# 验收依据与当前边界

完整产品范围以用户确认的 P0～P8 方案为准。当前最近完整行为基线为 207 项、0 失败；新增变更及包基线见 ImplementationStatus 和 FeatureMatrix，不能用测试数量换算功能百分比。

用户要求先完成功能与非实机验证，暂缓 Computer Use。当前允许的证据包括正式裁剪 API 编译、程序集边界、实际生产逻辑、公开宿主的原生资产/文档/History、离线 Shader、原生插件导出和无界面构建。没有运行 Editor GUI、GPU、音频设备或独立 Player 的结论。

| 领域 | 功能验收必须证明 | 当前证据/未通过边界 |
|---|---|---|
| 架构 | 十个职责边界、Runtime 无创作层引用、不依赖功能插件、全部写入限于仓库 | 正式编译和 PE 检查通过；验证宿主不调用引擎源码准备/缓存维护 |
| 剧情 | 图为唯一事实，类型/控制流/并行校验、源码定位、有限预算及候选恢复 | 分支、循环、跨章节调用、单交互焦点并行、命令及异常已有生产链契约 |
| 双主编辑 | 任意合法图结构可从两视图查看和修改；共享身份、事务、选择和 History | 卡片/紧凑/阅读稿、图连接/组编辑/审阅/原生保存已有契约；实际手势未实机验收 |
| 舞台/演出 | 声明状态、纯时间求值、精确目标冲突和存读档/回滚 | 镜头/跟随、角色部位、时间线、粒子、转场和效果已有逻辑契约；实际 Shader 输出未验 |
| 游戏 UI | 作者可编辑的同一页面体系、类型化绑定/动作、焦点/模态/输入消费及恢复 | 18 页面角色、三主题、组件、动画、鉴赏和设置已有契约；IME/手柄接入有公开 API 缺口 |
| 存档/进度 | 原生完整数据包、原子提交、候选失败保留当前会话、全局与普通状态分离 | 存储替身及 Editor 原生 codec 通过；自动 Runtime 根编码入口未导出，不能用其他格式替代 |
| 多语言/无障碍 | 稳定文本身份、翻译变化/缺字、语言资源、缩放和阅读偏好 | 原生交换/字体链/图片/高对比及减少动态已有逻辑；实际多语言排版、完整英文编辑器资源仍未完成 |
| 资源/模板 | 数量下限、来源许可、真实可编辑预设、普通 Game 资产实例及引用闭包 | 159 根资源、54 页面、五教学图与三起点已原生检查；视觉质量/试听/新手计时未验 |
| 扩展 | 明确 owner、封闭中立状态、预览/取消/恢复/副作用政策、代际释放 | 命令/动作/数据源显式注册通过；自动发现受 API 限制，自定义节点编译和完整表现扩展协议仍未实施 |
| 发布 | 无其他功能插件的包、全新消费编译、普通 Assets 运行闭包、Windows 产物 | 包/消费编译以状态页的实际包为准；Windows 构建曾遇现有 SDK/Support Pack 不一致，不代表已取得成品 |
| 稳定性/规模 | 大章节虚拟化、取消/进度、输入反馈、长期编辑和资源释放 | 一万节点真实编译/执行及可见行测试已有证据；完整十万句/两小时/设备泄漏与性能指标未验 |

标记完成必须同时具有可用模型、创作入口、运行行为、恢复策略、错误定位、说明和必要的行为证据。外部阻塞必须列出具体公开接口及影响范围；暂缓实机不能掩盖尚未实现的功能，功能也不能因 GUI 未验而被误记为未编码。
