# 创作交互与操作归属

所有创作操作通过 Authoring 的 detached candidate 和引擎 History 提交。下表记录当前已实现入口及其确定语义；实际鼠标、键盘、IME 与缩放显示按用户要求尚未实机验收。

| 创作任务 | 入口 | 语义与边界 |
|---|---|---|
| 指令创建 | 图/剧本 Tab 菜单和检查器 | 按类别/名称/ID 搜索；唯一 next 可直插。选项生成两片段及汇合；并行生成完整归属组。其他复杂输出保留原路径并要求明确连接 |
| 连续对白 | 卡片/紧凑正文、续写按钮 | Ctrl/Super+Enter 或单行空对白 Enter；普通 Enter 换段。续写保留角色/布局、重建文字身份并清除旧配音，定位新正文 |
| 图选择 | 原生画布指针与共享选择 | 框选、Ctrl/Super 切换、Shift 追加；取消、缩放/平移和文档切换不提交旧指针；图位置不改变执行顺序 |
| 剧本选择 | 有限执行段与可见行布局 | 主选择与图一致；Shift 范围、Ctrl/Super 切换；循环和汇合只列明确引用，不递归展开 |
| 剧本换序 | 卡片标题上/下半部、明确目标边、相邻按钮与 Alt+上/下 | 真实唯一连线定位；普通线性换序直接提交，复杂边界先审阅；保留节点/边身份，拒绝过期载荷和计划；正式编译、目标判定和原生 History/保存纳入 240 项完整回归 |
| 组复制/粘贴 | 同一中立剪贴板与审阅面板 | 内部身份重建，外部目标和变量按类型映射；无法解析的引用显示 Missing，不能猜故事意图 |
| 组删除 | 受影响连接审阅 | 单线路径可续接，复杂来源明确重连/断开；保护公开入口，要求完整并行边界 |
| 舞台画布 | 移动/等比缩放/旋转工具 | 按实际裁剪/旋转几何点选；基于冻结起点、统一网格与 Alt 解吸附；一项原生手势，Esc 取消 |
| 角色站位 | 显示角色指令 | 显式画布、边距、左中右/自定义比例与九点锚定；使用真实合成边界，不改角色源 |
| 演出编辑 | 时间线轨道/关键帧画布 | 组框选、追加/切换、整体位移/复制/删除；保持帧间距，默认拒绝冲突，空轨道删除和覆盖明确选择；标记独立 |
| UI 画布 | 边/角手柄、方向键、对齐 | 只直接变换允许的轴与布局所有权，保留锚点/枢轴；实际运行布局为测量依据 |
| UI 层级 | 同级按钮、明确新父/位置 | 保留 ID、坐标、动作和绑定，指出新布局/裁切/重复行上下文；树拖放处于当前后续验证批次 |
| UI 设计预览 | 共用 UiDocumentInstance 与 Rendering | 动画时间纯求值，不执行按钮/剧情动作；高对比游戏模式已通过行为验证，设计器预览开关处于后续验证批次 |
| 资源关联 | 原生所选资源按钮、匹配和批量工具 | 使用引擎 Assets/Identity。File Browser 的 native 拖放桥未导出，不能复制私有载荷协议 |
| 预览来源变化 | 草稿修订、dirty 和 contentVersion | 限量检查，旧会话可检查但禁止写回旧路线；重运行才建立新捕获 |
| 实际路线录制 | 局部/路线/完整预览 | 唯一输入 owner；显式初值、目标访问序号、选项/姓名步骤；变量调试仅作用于当前会话，显式写回用例 |

右键、按钮和快捷键中已接入的操作应调用同一编辑服务。不能用新增按钮数量代表完整工作流；新增交互必须补对应业务契约或原生 History 证据。
