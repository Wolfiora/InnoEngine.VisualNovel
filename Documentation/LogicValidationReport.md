## 当前功能范围

已形成共享图与剧本、15 类指令、变量与表达式、跨章节流程、玩家输入、二维舞台/角色、时间线、粒子、自有 UI 与九页游戏壳、音频、逻辑存档和回滚的基础链。资源设计入口与生产帧求值共用业务实现。

存读档服务有 Editor 原生 codec 和可控存储逻辑验证，正式 Runtime 原生根入口尚缺；不能据此声称发布游戏的文件存档已经可用。音频测试使用可控输出，不代表设备播放成功。界面、舞台与粒子预览已编译，不代表布局和画面质量已完成验收。

## 外部边界

当前选定正式 API 的 Runtime 根序列化、自动扩展类型查询、视口输入法组合态/手柄数据，以及无效草稿独立保存仍有缺口，见 `Decisions/0001-RuntimePersistenceBoundary.md` 和 `0002-FormalHostCapabilityGaps.md`。没有修改引擎源码或用反射/实现程序集绕过这些限制。

根目录除两个默认项目外的十个 `.csproj` 是引擎按 `.iasmdef` 生成的 IDE 文件，已忽略；生产结构仍由 Assets 和程序集定义决定。Tools/Tests 的独立项目分别承担原生引导、架构检查、分发检查、资源生成与契约测试，不参与插件运行时程序集。
