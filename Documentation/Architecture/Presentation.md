# 舞台、界面和绘制

Stage 由声明状态和逻辑时间产生 StageFrame，UI 由页面声明、绑定数据和逻辑输入产生 UiFrame。Rendering 将两者编成引擎四边形、文字与效果 pass；Integration 提交原生 RenderModel/Pipeline。剧情、舞台和布局不直接操作图形设备，也不依赖 Rendering2D 或 Canvas。

角色部位组合、裁剪、枢轴、混合、遮罩、镜头视差、呼吸和帧动画都使用 VN 舞台声明。文字塑形、字体回退和字形栅格化复用引擎 Text。VN 的富文本、Ruby、冻结插值和揭示节奏负责阅读语义，不复制字体后端。

可复用演出共用 StagePerformanceController 的逻辑时钟。舞台变换、UI 元素、音量和屏幕效果使用机制限定的参数通道；冲突替换明确，不依赖遍历次序。Seek 只求值演出，不执行解锁、保存或外部命令。减少动态效果和禁止闪烁在统一求值路径中处理。

UI 测量和排列使用引擎 Rect 等基本类型。页面实例拥有焦点、模态、滚动、重复行和临时交互；文档只保存声明。游戏持久字段通过明确的 UiPageStateSnapshot 保存，页面局部字段和悬停不进入普通存档。

UI 事件动画与剧情时间线分开：前者表达 Enter/Exit/Hover/Focus/Pressed/Waiting，后者是游戏演出。父子变换、透明度和裁切组合后同时用于绘制和命中。页面退场冻结上一页绘制指令，不保留旧页输入或动作；新页是唯一输入 owner。稳定缩略图排除临时事件动效，保留实际演出。

界面设计器复用运行布局结果。画布拖动、八向缩放、网格和对齐仅修改原生布局声明，保留锚点、枢轴和自动布局所有权；连续手势通过引擎 EditorEditGesture 合为一项历史。动画预览不执行游戏动作。

Shader 离线编译和 RenderGraph/几何契约不能证明实际 GPU、字体显示或设备输出。本轮没有实机验收，视觉结论保留在实施状态中。
