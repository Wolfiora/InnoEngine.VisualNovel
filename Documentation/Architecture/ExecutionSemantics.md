# 执行语义

StoryMachine 持有显式指令位置、调用栈、变量作用域、随机状态和等待。不存在需要保存的 CLR Task 或协程栈。即时执行受预算约束；没有等待的循环产生带源节点的 Faulted 状态，不阻塞编辑器。

对白按字素簇揭示。一次推进先完成揭示，后一次才继续；选项和姓名输入独占交互，确认不会透传到下一条指令。语言切换和恢复使用冻结替换值重新排版，不再次读取已改变的插值变量。NVL 页面是声明性阅读状态，独立于历史和全局已读。

并行组按明确分支顺序在同一逻辑更新执行，整个会话最多 64 个任务、8 层嵌套。每组至多一个分支包含交互指令，其他分支继续演出和计时。文字速度只作用于揭示。不同变量可以并行写入，相同变量竞争会拒绝；Game、当前调用 Local 与 Global 使用父会话的共享作用域。

等待全部在所有任务到达所属汇合点后继续；等待任一取消剩余任务，释放其拥有的音频、演出、粒子、效果和说话标记。取消不撤销已提交的即时赋值。完成的交互分支交回 NVL 页面，被取消的页面不并入父会话。

子任务交互次序、选择结果和姓名结果传到根会话；UI 读取唯一 interactiveOwner，调试和快照仍读取根任务树。存档、回滚和路线目标可以停在子任务内部。恢复候选检查子任务变量与父作用域一致、选项标记归属、等待与指令匹配，然后才替换活动会话。

扩展声明可预览、取消、保存、恢复、回滚和外部副作用。不能恢复的活动命令禁止保存；不可逆动作形成回滚屏障。并行中的扩展必须满足安全继续约束。预览不会默认执行外部副作用。
