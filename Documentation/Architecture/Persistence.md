# 保存、恢复和回滚

普通存档包含游戏身份、严格构建指纹、剧情任务树、调用局部值、阅读和选项、舞台/时间线/粒子/转场、音频位置与淡变、游戏持久页面字段、历史和展示信息。GPU 资源、活动委托、订阅、CLR Type 和线程不保存。

SaveService 通过 INovelSaveStore 和 INovelStateCodec 使用原生结构化序列化。槽位提交完整包；列表索引可重建，失败不破坏原有效包。手动、快存和轮换自动槽彼此独立；标题继续寻找最近有效且兼容的普通数据包。

读档先构造剧情、舞台、音频和 UI 的候选，验证全部资源、等待、子任务作用域和内容指纹，再替换当前会话。损坏、不匹配或准备失败时保留当前游戏。异步返回结果使用 owner 与状态修订检查，不能覆盖已经停止或重新开始的会话。

准确帧截图与逻辑状态来自同一边界，渲染/回读资源独立拥有；PNG 缩略图和状态一起提交。预览使用自己的内存存储，不读取或污染玩家槽位。

已读、收藏解锁和 Global 变量单独作为全局进度；偏好又单独保存。普通读档和回滚不会撤销已经获得的全局进度。局部和 Game 变量恢复到检查点；随机流、演出和语音遵循明确恢复政策。回滚后丢弃旧未来，不能跨越不可逆屏障。默认保留 100 个检查点，可配置数量。

配置原生 codec 时，回滚只保留编码缓冲区，默认原生载荷预算 64 MiB；小型边界元数据另受检查点数量上限约束。超预算淘汰最旧缓冲区，单个过大点明确略过，不保留第二份解码对象。读取时才准备独立候选。预算可以从原生组件的 rollbackBudgetMiB 调整，0 禁用保留；Codec 编码失败给出诊断，不破坏当前游戏或其他有效点。该功能的当前验证状态见实施状态，不将原生缓冲区预算表述为整个进程或 GPU 的硬内存上限。没有 codec 时只保留原有数量限制，字节占用为未知。

不提供旧格式 reader、schema version、隐式迁移或兼容 alias。普通存档严格匹配当前内容构建。

当前正式 Runtime 未导出根序列化入口；SerializationRegistry 只在 Editor scope 可用，Reader/Writer 构造不公开。Editor codec、存储端口、故障替身和完整逻辑链已测试；独立 Player 的自动原生 codec 接入仍受 [决策 0001](../Decisions/0001-RuntimePersistenceBoundary.md) 限制。没有另建 JSON 或手写二进制格式。
