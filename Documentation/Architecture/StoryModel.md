# 唯一剧情模型

`.ivnstory` 的 GraphDocument 是执行顺序的唯一事实。节点、文本、选项和连线使用稳定 ID；片段记录归属，入口映射到节点。图坐标、数组顺序、片段折叠和阅读稿显示均不决定执行。

`StoryDraftState` 是引用中立的原生文档快照。共享变量库通过引擎持久身份关联；有效声明由库与章节合并，重复声明会诊断。Model 只保存封闭类型的变量、表达式、节点参数和资源声明，不保存任意 CLR 对象。

剧本投影以有限执行段表示自由图，保留分支、汇合、循环、跨片段目标和 Missing 数据。卡片、紧凑和阅读稿共享同一文档、选择和 History。投影不会递归展开循环或复制语义。

拓扑编辑在 Authoring 中准备候选。插入拆开一条边；普通单入单出删除可以保留后续；复杂删除须明确处理受影响连接。复制重建内部身份并保留明确的外部目标政策。换序先展示三条连接变化，正式编译通过后，作为一项引擎事务应用；不能通过视觉排序暗改执行。

编译器执行引擎图校验和 VN 语义检查，降低为 StoryProgram，保存来源映射、稳定目标与内容指纹。Runtime 只消费编译产物。预览把明确选择的当前草稿编成内存产物，再走同一运行链，不修改 canonical 导入资产。

当前原生源保存需先成功导入，无效/Missing 草稿的独立保存仍受公开 API 限制；文档可保留中立数据，不把保存失败显示为成功。
