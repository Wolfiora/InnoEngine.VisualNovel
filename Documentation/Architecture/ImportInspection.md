# 导入候选与只读内容检查

项目指纹计算必须使用 AssetImportContext 提供的候选代际。EditorAssets.CaptureProperties 依赖编辑器全局资产作用域，不能用于这一导入路径；全局作用域还可能指向候选以外的资源。

AssetSerializationServices.CaptureProperties 会向导入事务登记每一个捕获引用。对每个资源重复检查会重复登记同一字体或图像，因此也不能直接将它作为只读遍历接口。

当前传统 VN 资源采用正式 NativeAssetSourceSerialization 的类型化导出/读取获得原生字节及依赖描述。引用收集局限于一次原生操作；上下文仅通过显式资源解析登记依赖。没有读取或复制引擎的私有封装格式，没有反射构造内部对象。

覆盖 VN 项目、章节、变量库、角色、舞台、演出、效果、页面、主题、音频提示、翻译、收藏和扩展声明目录，以及正式材质、Shader、图像、字体、音频资源。根源字节、每个引用源和导入数据共同参与严格内容指纹。

任意第三方资产类型需要额外只读捕获契约。当前公开接口不能在禁止重复登记依赖的前提下泛化这一操作，因此不静默忽略未知资源；附加资源明确报错。最小宿主需求是候选代际所有的、可不登记导入依赖的属性和依赖捕获入口。这不影响上列已实现的传统 VN 资源，亦不允许修改引擎或另建序列化系统。
