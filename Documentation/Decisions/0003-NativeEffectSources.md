# 原生效果资源采用具体根类型

当前正式 NativeAssetSourceSerialization.Import 要求源头中的稳定类型身份与导入器的具体目标类型完全一致；不能用一个抽象 AssetObject 基类导入任意派生效果。该约束已由原生资源测试实际验证，不通过反射或改动引擎绕过。

`.ivneffect` 使用具体 `VisualEffectAsset` 作为原生源根；实际粒子参数由中立 `ParticlePreset` 值对象保存。Stage 复制声明，运行时只保留资源键、种子、时间和放置状态。源、编译/导入产物与快照仍使用引擎序列化。

目前只实现粒子；不添加无法执行的转场或屏幕效果分支。增加其他效果时须给出真实参数、验证、求值和创作入口，再扩展这个源契约。

内置资源生成器写入新的、独立的源声明，不将加载后的 canonical AssetObject 当作源直接重存。干净包安装曾发现两个动作资源被错误记录为开发项目自身引用；已修复生成路径，并由仅安装插件包的全新消费工程正式编译验证。
