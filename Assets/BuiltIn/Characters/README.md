# 分层教学角色

澄（Cheng）与树（Shu）各提供自然站立、挥手两种姿势，以及平静、微笑、难过、生气、惊讶、害羞六种表情。后发、身体、脸、表情和前发分别保存为透明 PNG，构图统一为 768×1152；原生角色以 600×900 逻辑尺寸组合。

在 VN 内置资源创建角色项目副本，再用 VN 角色设计器编辑部位、顺序、姿势、表情和呼吸。原始矢量声明位于 Tools/BuiltInResources/OriginalCharacterArt.cs；同一声明导出的 SVG 位于 Tools/ArtResources/Sources/BuiltIn/Characters。
