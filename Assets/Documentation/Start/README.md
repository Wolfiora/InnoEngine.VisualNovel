# 当前创作与预览流程

本指南描述已经实施的工作流，不代表完整 v1 已交付。本批次按用户要求只执行正式编译和逻辑测试，没有启动窗口或验收这些设计器的实际布局、手感、音频设备与成品画面。

## 创建游戏

1. 用匹配的 InnoEngine 打开工程，等待脚本编译。
2. 打开 `Window → Authoring → Visual Novel`。
3. 展开「创建可运行游戏」，选择标题和 Clear/Paper/Cinema 配色，点击「创建视觉小说」。
4. 向导创建 `Assets/Game/Novel-*/` 下的章节、当前 17 个页面角色、翻译表、收藏库、游戏定义、原生材质和启动 Scene，并关联内置标题音乐。正式游戏不会依赖 `~Samples`。
5. 使用引擎 Play 和 Game 视图运行。向导维护默认 Scene 接入，不需要手工创建 Pipeline。

当前页面包含标题、阅读、暂停、设置、历史、名单、存档、读档、确认、鉴赏分类、CG、音乐、回想、结局、词条、角色资料和收藏详情。三种配色不等于三套完整主题；NVL/气泡等阅读类型和完整启动/加载等行为仍待补齐。存读档页面需要宿主接通原生存档服务；缺少服务时按钮明确禁用。

## 图与剧本

- 「创建分支故事」创建原生 `.ivnstory`；在 File Browser 选择章节后可用「打开所选章节」。
- 剧本、图、属性、章节和变量页操作同一个文档、稳定 ID 和引擎 History。
- 图中中键平移、滚轮缩放、拖动节点、连接执行端口。布局不改变执行顺序。
- 新建指令选择类型；输出目标也能在表单中明确选择。选项删除会显示受影响连线。
- 当前 16 类指令包含对白、选项、赋值、条件、等待、调用/跳转、返回、随机分支、断言、舞台、音频、演出片段、玩家输入及收藏解锁等。
- 对白可填写语音提示资源 ID，也可在 File Browser 选择 Voice 类提示后直接绑定。语音必须不循环，且已关联到游戏资源库。
- 玩家输入提供默认值、字素长度范围、取消分支和结果变量。首次确认只提交输入，不跳过下一句。
- 可复制节点后粘贴；内部节点/选项/台词身份重新分配。无法解析的跨章节外部连接保留 Missing，不猜测目标。
- 次数循环模板生成普通赋值、条件、递增和执行边，两个视图都能继续编辑。
- 表达式支持类型化列表的计数、读取、包含、追加、删除、插入和替换。修改列表的表达式返回新列表，应通过赋值写回。
- 随机范围只允许在显式赋值中求值，不能在反复刷新的选项条件中消耗随机状态。
- `{player}` 插入变量；`{{` 表示左花括号。文字按字素簇揭示。
- 调用的目标章节留空代表本章，填写其他章节 ID 则连接其公开入口。「改为跳转」会明确删除返回连接，不增加调用栈。
- 诊断保留节点位置。无等待死循环受到即时指令预算限制。

当前引擎要求资产保存先通过导入，因此未连接或无效图可以保留在当前草稿中，却暂时不能保存为失败源。完整批量手势、复杂移动预览、搜索与调试矩阵尚未齐全。

## 关联资源

打开 `VN 游戏设置`，在 File Browser 选择 `.ivnproject` 后打开。随后选择已有章节、舞台、角色、音频提示、演出片段、页面、字体或材质，使用「添加或替换所选资源」关联。选择导入的音频文件可设置标题音乐。页面使用明确的 shell role；资源 ID 是剧情指令使用的稳定键。

关联与表单编辑均进入引擎 History。保存游戏定义时会检查入口和资源，生成包含原生资源闭包的保守构建指纹。Runtime 根序列化服务尚未公开，因此当前不能宣称发布游戏的正式文件存档已经接通。

## 界面设计

1. 打开 `VN 界面设计`，创建页面或打开向导生成的 `.ivnui`。
2. 页面树选择父元素，添加控件；支持复制、删除子树。复制会给内部元素分配新身份。
3. 在属性区编辑位置、尺寸/范围、锚点、枢轴、间距、颜色、图片适配和文字；常用值、显隐、可用条件、列表及点击动作通过选择器配置。
4. 在 File Browser 选择游戏后可点击“使用所选游戏的变量”，将它的声明加入绑定列表；打开页面动作直接选择目标页面，滑块仅提供数值字段选择。
5. 在 File Browser 选择图像或字体后，可将其赋给选中元素。
6. 画布点击选择控件；绝对定位容器中的控件可拖动，Escape 取消当前拖动。
7. 预览使用正式 UI 和渲染链，以及明确的示例数据；设计模式不执行真实游戏动作。
8. 保存、Undo/Redo、关闭和重开共用原生资源文档。

控件和设计器还没有覆盖完整计划。不能用编译通过替代视觉、焦点、缩放、窄屏和手柄的实机验收。

多语言的文本同步、复核与 CSV/TSV 交换见 [游戏多语言](../Authoring/Localization.md)。收藏条目、解锁、音乐播放器及回想初值见 [收藏、鉴赏与回想](../Authoring/Collections.md)。新建游戏已有可编辑的英文教学文字及音乐、回想和词条条目，可直接从标题的“鉴赏与资料”进入。

## 舞台与角色

- `VN 舞台设计` 可创建舞台、添加纯色层、将所选图像赋给图层，调整顺序、合成分组、变换、透明度、视差和显隐。
- `VN 角色设计` 从所选图像创建角色，支持复制姿势、添加共享部位、表情差分图像/显隐/偏移与实时构图预览。
- 删除共享部位的按钮明确说明会同时移除所有姿势和表情中的对应部位。
- 先将资源关联到游戏，再用「舞台与角色」指令指定资源 ID、角色实例名、姿势与表情。
- 当前采用二维图像组合，不包含网格变形、Live2D 或骨骼编辑。

## 时间线

- `VN 演出时间线` 创建 `.ivnclip`，添加目标槽和属性轨道，写入关键帧并选择 Linear/Hold/Smooth 插值。
- 点击关键帧选择，拖动按 0.05 秒吸附；Escape 撤销当前拖动。碰撞已有时间的关键帧不会静默覆盖。
- 指定一个已有舞台及明确的目标绑定，拖动预览时间进行纯求值。
- 位置是相对初始构图的偏移，缩放和透明度是乘数，旋转围绕该对象的构图原点。
- 剧情「演出片段」指令支持 Play/Wait/Pause/Resume/Cancel/Seek。目标可用 `camera`、`character/实例名`、`stage/图层 ID`。
- 同一目标属性只有一个活动写入者；新的演出会替换发生冲突的旧演出。完成后保持最终姿态，Cancel 移除覆盖并恢复底层构图。
- 逻辑时间、绑定、暂停和活动写入者均随舞台快照保存。时间线拖动不执行剧情、存档、解锁或外部脚本。
- ShakeX/ShakeY 是独立震动通道，可与平移共存。减少动态效果会跳过装饰性单次动作并固定装饰性循环；标为 essential 的动作继续运行。
- `BuiltIn/Motions` 含 20 个可编辑预设，角色目标槽为 actor，镜头为 camera。完整资源浏览与缩略图库尚未完成。

转场、屏幕效果、高级曲线编辑、同步标记、音量/UI 轨道等演出仍待实现。

## 粒子

- `VN 粒子设计` 创建或打开 `.ivneffect`，编辑发射区域、速率、持续时间、随机生命期、速度、加速度、旋转、线性尺寸/颜色变化、分层与精灵。
- 逻辑时间和种子预览使用正式 Stage 及渲染链，不建立另一套模拟器。每个发射器最多 4096 个理论活粒子，全舞台最多 16384，最多 32 个发射器。
- 先将效果关联到游戏，再用舞台指令选择 StartParticles、StopParticles、RemoveParticles、WaitParticles。相同实例的 Start 明确替换旧实例。
- 持续发射需先 Stop 才能等到全部消退；Remove 立即取消。减少动态效果会隐藏并暂停可选粒子，且不让等待被装饰性效果卡住。
- `BuiltIn/Particles` 包含八个带原创精灵的参数预设，说明和默认值见其中 README。通用的包资源复制界面仍待实现，安装内容本身只读。
- 快照保存资源键、种子、逻辑时间和位置，不保存线程、随机对象或 GPU 句柄。当前测试证明同一状态的几何可重复，不表示不同 GPU 输出逐像素一致。

## 音频与保存的当前边界

`VN 音频提示` 从 File Browser 中选定的已导入音频创建 `.ivnaudio`，编辑名称、来源、资源 ID、分类、循环、音量与淡变；共享原生文档和 History。音频指令提供 Play/Stop/Pause/Resume/Wait。对白语音只在进入台词时播放一次，自动阅读等待语音结束，历史可重播；「推进时停止语音」由玩家设置控制。标题音乐在访问设置时保持，开始游戏时释放。实际设备播放、波形、批量配音及每角色策略尚未验收或未完成。

`SaveService` 已实现原生数据包、100 个默认手动槽、3 个自动槽、1 个快存槽及候选读档。存档页每页十个槽位，区分手动/自动/快存；覆盖、删除、读档先确认，IO 错误保留当前游戏。`SaveSlotController` 只在 owner 线程 Poll 时应用读档；迟到读档不会替换已重启的游戏。自动槽位轮换已有服务逻辑，但剧情自动保存触发仍待接入。

宿主可以在创建会话前调用 `NovelPlayerComponent.ConfigurePersistence(storage, codec)`；`NovelGameView` 也可接收匹配构建的 `SaveService`。需要宿主提供 `INovelStateCodec` 的 Runtime 原生实现后才能接入正式游戏文件存档；当前仅有 Editor 适配。存储和音频故障测试采用可控替身，未使用 JSON 或自制二进制旁路。

安装包资源只读；修改前先通过正式资源机制创建项目副本。所有未完成项以仓库实施状态和功能矩阵为准。
