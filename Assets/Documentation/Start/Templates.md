# 项目模板与五组教学样例

在 VN 工作区点击「创建视觉小说」，选择项目起点、主题、游戏语言与设计分辨率。向导会生成原生 Game 资源及启动场景；页面、角色、舞台和演出都可继续编辑。

三种项目起点：

- **空白视觉小说**：完整游戏壳和一条开场台词，不放入角色或舞台指令。
- **短篇分支故事**：角色出场、对白、双路线与背景变化，适合开始短篇创作。
- **演出与界面功能展示**：目录连接逻辑、演出与界面三个独立章节。章节结束后返回标题重新选择。

同一个选择器中提供五组教学样例：首个故事、分支与循环、演出展示、界面展示、脚本扩展。它们分别生成同一份教程工厂声明的普通原生图，图与剧本视图可以交替编辑。脚本扩展这一组需要按配套说明注册正常 C# 类，其余四组不需要用户脚本。

所有实例化内容写入新的 `Assets/Game/Novel-…/`，拥有新的资产、章节与台词身份。主题各页、舞台、角色、动作和粒子定义使用可编辑副本；安装包内的字体、图片及音频保持只读引用。正式游戏不依赖 `~Samples` 中的教学源。

不同设计分辨率使用相同等比适配：背景、角色、位移轨道、震动和粒子尺寸/速度一起缩放；宽高比不同时居中保留边缘区域。UI 使用自己的设计画布等比适配，可在界面设计器中调整。

每次创建都会建立新的独立游戏，不会覆盖上一次作品。若原生导入失败，已创建资源会保留并报告位置；修复诊断后可重新创建或继续编辑。

本批次只进行正式脚本编译、原生导入和行为测试；没有实机、GUI、音频听感或新用户计时验收。
