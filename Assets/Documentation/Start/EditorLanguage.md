# 编辑器语言

在引擎 Settings 打开 `Editor → Visual Novel → Language`，选择简体中文或 English，再使用引擎 Apply。Undo/Redo 会还原这项项目偏好；重新打开项目后仍使用已应用的选择。

这项设置只影响 VN 创作界面。游戏的默认语言、翻译表和玩家语言偏好继续在游戏设置与游戏页面中配置；切换编辑器语言不翻译作者写入的台词、角色姓名、变量名称或资产名称。

节点图的名称、类别和端口在显示时翻译，原有节点身份和连接不改变。资源目录可使用原名称、英文名称或路径搜索；内置说明按当前编辑器语言显示。用户创建的副本内容保持原值。

语言资源加载失败时保留最后可用的显示语言，工作区显示具体错误。修复插件资源后重新应用语言即可；普通文档与 History 不会因此丢失。

当前面板正文和原生设置有无界面逻辑证据，余下动态消息仍在接入。原生浮动窗口标题来自固定 attribute，宿主尚未提供动态标题接口；实际 GUI、键盘焦点与英文上手尚未验收。
