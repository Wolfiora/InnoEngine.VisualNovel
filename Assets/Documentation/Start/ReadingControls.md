# 阅读与按住快进

推进时，第一次操作补完当前台词，下一次才继续剧情。选项、玩家输入与模态页面先处理自己的输入，确认不会同时跳过随后出现的台词。自动、切换快进和隐藏界面也可通过可编辑阅读工具栏操作。

按住单独的 **Ctrl** 开始临时快进，松开即停止。遵循玩家的「仅快进已读内容」设置；遇到未读台词、选项、玩家输入、明确的脚本屏障，或菜单、文本输入焦点、下拉弹层和输入法组合时停止。持续按住不会在障碍消失后重新开始；松开并再次按下才会重试。点击工具栏切换的持续快进属于独立操作，松开 Ctrl 不会取消随后明确切换的模式。

窗口/视口失去交互权限时立即撤销临时按住状态；重新获得交互且 Ctrl 仍按住时，必须先松开。带 Alt、Shift、Super 或其他按键的组合不会成为新的按住快进。当前按住键固定为 Ctrl；七项普通阅读动作已提供[快捷键设置](../Interface/KeyboardSettings.md)，完整导航与组合键重映射仍未实现。

这些是瞬时输入状态，不随存档恢复或回滚；恢复会话后不会自动恢复按住快进。宿主通过正式 `RenderOutputInput` 的交互许可与修改键映射，不使用全局键盘钩子或另建输入系统。

正式 Scripting API 编译、十程序集检查、七项相关定向契约及 165 项完整回归通过，包含实际游戏 UI、正式宿主输入样本和原生会话恢复。实际窗口焦点、真实输入法组合、键盘设备和 GUI 均未进行本批实机验收。正式视口尚未提供输入法组合态，因此组合保护已经在 UI 域实施，宿主仍有已记录的 API 缺口。
