# 滚动区域

界面设计器的 Scroll 容器由同一 VN 布局系统计算内容高度。超出可见区域时，实际游玩界面自动显示滚动轨道与比例滑块；不需要脚本或额外图片资源。没有溢出时不显示无效滚动条。

拖动滑块可快速定位长列表，按住拖出视口仍保持此次拖动；松开后释放输入。点击轨道上方或下方翻动约一页，不会同时点击内容里的按钮。滚轮、PageUp/PageDown 和焦点自动滚动继续可用。嵌套容器只处理最前面的有效 owner，后绘制的遮挡页面优先接收指针。

滚动条使用当前页面的前景和焦点颜色，高对比模式使用深色轨道与黄色滑块。它是运行时操作提示，不新增页面元素、剧情变量或保存格式。设计模式、存档截图和页面退场不保留它；关闭页面会取消拖动。NVL 等跟随文字揭示的页面沿用原来的跟随末尾政策，手动移离末尾后停止跟随。

目前只进行布局、输入和绘制声明的命令行逻辑验证；实际像素、非整数缩放、设备操作手感没有实机验收。
