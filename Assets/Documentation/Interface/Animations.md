# 页面与控件动画

在「VN 界面设计」选择元素，展开「显隐与交互动画」。六类事件分别拥有独立的开关、时长、延迟、缓动、透明度、位移和统一缩放：

| 事件 | 行为 |
|---|---|
| 入场 / 显现 | 从指定姿态回到正常姿态；页面重新进入、条件重新成立时触发 |
| 退场 / 隐藏 | 从当前姿态走向指定姿态；隐藏立即停止接收指针和键盘输入 |
| 悬停 | 指针进入时走向指定姿态，离开时平滑返回 |
| 焦点 | 焦点进入时走向指定姿态，失去焦点时平滑返回 |
| 按下 | 指针按住时走向指定姿态，释放后平滑返回 |
| 等待循环 | 条件成立时往返运动；条件留空表示持续开启 |

「淡化」「下移淡化」「轻微缩放」会填入可继续编辑的普通动画参数。等待条件可以选择 Boolean 游戏变量、页面状态或已声明的数据源字段。组件模板携带动画专用页面字段，插入时会重建字段引用。

动画不改变布局和文字换行。父元素的位移、缩放、透明度以及裁切会作用于整个子树；实际命中区域跟随显示位置。透明度相乘、位移相加、统一缩放相乘，焦点与悬停同时存在时结果明确。条件显隐在动画中途反向时从当前姿态继续。

在画布勾选「动画时间预览」，选择事件并调整时间，可直接查看结果。该模式使用游戏 UI 的真实布局和绘制数据，不执行按钮、脚本、存档或解锁；关闭后恢复普通选择和拖动。等待事件可以跨越多个循环查看。普通设计模式显示稳定姿态，避免入场初始透明度遮住编辑目标。

页面切换会冻结最近显示的旧页面，只让它继续退场；旧数据源、按钮和输入控件不再运行。新页面独占输入。快速切换时新的退出页面替换旧退出页面，不累积后台页面。读档或回滚会重建临时交互与入场状态；页面持久字段仍由原来的状态系统恢复。

存档缩略图排除提示、下拉框和事件动画，使用当前剧情边界的稳定页面。时间线驱动的 UI 表现属于剧情演出，会进入同一舞台快照和准确边界截图。

玩家开启「减少动态效果」后，事件动画立即回到稳定姿态，等待循环停止，页面退出不再延迟。文字缩放与文字揭示不受影响。
