# 主题与页面

在「VN 主题设计」中创建或打开 `.ivntheme`。主题保存颜色 token、尺寸 token、可继承的样式类，以及系统页面映射；页面仍是普通 `.ivnui`，可以在「VN 界面设计」里修改。

Clear、Paper、Cinema 分别提供 18 个页面。Clear 使用现代左侧阅读层级，Paper 使用居中的纸页构图，Cinema 使用宽屏标题与横向菜单。它们共享系统动作和数据绑定，但拥有独立页面、字号与控件状态。当前已通过布局逻辑测试，尚未进行真实界面验收。

## 修改样式

1. 在主题设计器添加颜色或尺寸 token，再选择样式。
2. 选择父样式，勾选本样式实际定义的字段。未勾选的字段继续继承。
3. 每个字段可以使用固定值，或选择类型匹配的 token。颜色字段不会接受尺寸 token。
4. 修改 token 会影响所有绑定字段；重命名 token 会同步本主题中的绑定，删除仍被使用的 token 会报错。
5. 在界面设计器选择主题后，可从菜单给元素指定样式类。修改某项固定样式时，会自动勾选该项「页面局部覆盖」。取消覆盖后，该项重新跟随主题。

普通、悬停、按下、禁用、禁用文字和键盘焦点可以分别编辑。字体缩放在主题样式解析后应用；长选项和禁用说明使用内容高度。页面中的稳定样式键属于引用身份，不能以兼容别名隐藏缺失引用。修改或移除引用前，先在页面中重新关联；发布检查会验证每个主题。

主题设计器预览与游戏使用同一个 `UiDocumentInstance` 和正式渲染适配链。设计预览提供示例数据，不会执行页面的游戏动作。页面的绑定、动作与源文不会因为样式预览而改变。

## 在游戏中使用

在「VN 游戏设置」中附加所选主题，并选择默认主题。系统设置页通过 `game.theme` 字符串与 `themes` 类型化集合切换主题；按钮也可以使用 `theme` 动作，固定参数填写资源 ID。

切换保留剧情、音频和菜单返回路径。当前主题属于游戏快照，会随普通存档和回滚恢复；玩家音量、语言等偏好仍单独保存。缺失主题的存档会在准备候选时失败，当前游戏保持不变。

主题可以只覆盖一部分系统页面，其余角色使用游戏默认页面。不能映射游戏未声明的角色。导入和发布检查会验证页面结构、初始焦点、样式、选项数据类型和剧情所需的阅读绑定；某个主题不能因为暂时未被选中而跳过检查。

## 安装资源与项目副本

安装包内的主题保持只读。新游戏向导会在普通 `Assets/Game/` 子目录下创建三套主题及 54 个独立页面源，重新分配原生资产身份，再关联生成的游戏定义。它们不依赖 `~Samples`。复制后的修改通过引擎文档和 History 记录，不会写回插件安装目录。
