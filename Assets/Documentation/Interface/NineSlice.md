# 九宫格图片、着色与透明度

在界面设计器选中有图片的控件，将「图片适配」设置为 `NineSlice`，填写四侧边框的**源图片像素**。中间和四条边沿随控件尺寸伸展，四角保持边框像素缩放，不随整个控件被拉长。

- 「边框像素缩放」决定一个源像素对应多少设计像素。
- 「绘制中间区域」关闭后可制作只有边框的装饰。
- 「使用图像四分之一作为边框」提供可继续调整的起点。
- 控件小于边框总尺寸时，边框按比例压缩，不产生反向几何。
- 边框不能超过源图片尺寸。动态图片在解析后再次验证，错误会保留资源位置。

图片着色独立于文字颜色，位于「图片着色」。控件的不透明度同时影响图片、文字和背景；图片不会再忽略这项设置。`Stretch`、`Contain`、`Cover` 仍适合普通立绘、封面与截图。

九宫格可用于导入图片，也适用于生成的 UI 位图。图片源 UV、边框、着色与透明度都经过生产渲染提交；中立 UI 快照会保留这些声明。修改创作源不会改变正在运行会话的边框参数。

原生数据、几何、角区尺寸、小尺寸压缩、顶点 UV、图片透明度及保存恢复的逻辑测试已通过。尚未进行真实 GPU 或设计器操作验收。
