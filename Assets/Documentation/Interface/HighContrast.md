# 高对比阅读

三套内置主题的设置页都有「高对比阅读」，也可把任意切换控件绑定到 `settings.highContrast`。玩家偏好独立于游戏存档和回滚；开启它不会更换作者选择的主题。

高对比模式使用不透明深色文字表面、白色文字和醒目的黄色焦点。富文本中的局部暗色会被覆盖，粗斜体、字号、Ruby、行内图像、停顿和逐字揭示保持原样。舞台、美术图片、透明的点击推进区域和输入几何保持原样。下拉框和提示说明也使用这一套绘制策略。

关闭后立即恢复原主题颜色。该设置与「字体大小」「减少动态效果」「允许闪烁效果」分别控制不同需求，可同时使用。玩家偏好的生产自动落盘仍遵循文档中列出的 Runtime 原生序列化 API 边界。

逻辑与原生契约纳入自动验证；实际字体、屏幕和视觉舒适度尚未实机验收。
