# 阅读快捷键设置

玩家设置页提供七项可编辑阅读快捷键：自动播放、切换快进、隐藏界面、历史、回滚、快存和快读。默认分别为 A、S、H、L、R、F5、F9。可选择字母 A～Z、功能键 F1～F12，组合 Ctrl、Shift、Alt、Ctrl+Shift 或 Alt+Shift，或「未设置」禁用某项。完整组合冲突时，选择器保留旧值并显示原因；先解除另一项的组合，再重新分配。同一字母可以配不同修饰键分别使用。点击「恢复默认快捷键」一次恢复七个动作和默认按住快进策略。

这些控件是普通可编辑 UI：`settings.shortcuts` 提供稳定动作身份的行，`item.name` 提供已翻译名称，`item.shortcutKey` 提供枚举值；选择器的选项绑定为 `settings.shortcutKeys`。可在界面设计器中调整布局、样式或复用这些组件，重置按钮绑定 `keyboard.reset`。发布检查器验证精确的重复行归属、枚举成员和选项类型，不将同名自定义字段解释为内置快捷键。

「菜单导航键」另有八项：确认、下一项、上一项、增加/向右、减少/向左、上翻页、下翻页和返回/取消。它们使用 `settings.navigationShortcuts` 的独立稳定行，选项来自 `settings.navigationKeys`；默认分别为 Enter、下、上、右、左、PageUp、PageDown 和 Escape。可以选择这些导航键、字母/功能键及相同修饰组合，或明确禁用一项。阅读动作和导航动作不能使用相同的有效组合。两个列表共用同一重置按钮。

打开选择器后输入名称或组合即可筛选，例如 `Ctrl+Q`。文本字段里输入重绑定的普通字母仍然输入文字，不执行导航或取消；物理左右键、Home/End、删除/选区与 Enter 提交保留文字编辑职责。Tab、Shift+Tab 与 Space 保留基本键盘访问，不放入可重映射列表。

快捷键仅从正式视口的本帧按键和精确修饰键产生。在输入框、输入法组合、下拉弹层、其他模态页面或已经消费输入的控件中不执行；同一帧只处理一项。多个快捷键同时按下时，按快读、快存、回滚、历史、隐藏、快进、自动播放的固定优先级处理。Ctrl+Alt 不解释为 Ctrl，以免与 AltGr 输入混用。

「按住快进组合」可配置为 Ctrl、Shift、Alt、Ctrl+Shift、Alt+Shift 或关闭，默认 Ctrl。绑定为 `settings.holdSkipModifiers`，选项来自 `settings.holdSkipChoices`。使用组合操作、修改策略或暂停视口后，先松开修饰键再按住才重新启用快进，不会把设置操作继承成剧情快进。

快存快读复用原有服务可用性、槽位和读档确认；未配置持久化服务时不暴露可执行的快捷操作。历史沿用正常页面栈，回滚检查仍由会话负责，快捷键不会越过保存或回滚限制。新映射不会把同一次确认重复用于下一句对白。

映射属于玩家偏好，具有独立副本、原生序列化和候选应用语义；读取新玩家设置后，页面立即查询新实例。剧情读档或回滚不会恢复旧按键设置。正式 Runtime 自动落盘仍受已记录的原生根 codec 缺口影响，不能把原生数据往返测试当成独立成品的偏好持久化验收。

阅读、菜单导航和按住快进策略分别拥有明确绑定；手柄映射仍受宿主 API 缺口限制。嵌入式宿主使用 `UiInputSnapshot.textLeft`、`textRight`、`textConfirm` 表达文字编辑，普通 `increment`、`decrement`、`confirm` 表达导航动作；正式 `InnoNovelInput` 已负责这一映射。实际键盘、窗口焦点和真实输入法未进行本批实机验收。
