# CG 多图与图片视口

在「VN 收藏」编辑 CG 条目，封面仍用于鉴赏列表。在「CG 多图变体」中选择已导入图片，添加变体，编辑名称、顺序与附加解锁条目。变体身份稳定；更换名称或图片不会改变它。

没有变体时，详情显示普通封面。有变体时，详情只浏览可用变体。每张变体都要求所属 CG 已解锁；附加解锁可以选择同一库中的结局或其他条目。未满足条件的图片和名称不会出现在详情浏览中。后来解锁更多图片时，保持当前变体身份，避免浏览位置跳动。

默认详情页使用普通可编辑「图片视口」控件，以及上一张、下一张、放大、缩小和适应按钮。所有页面元素都能在界面设计器中修改，图片动作的目标从视口菜单选择。

- 鼠标滚轮围绕指针位置缩放，拖动查看放大的区域；移出视口后仍由原拖动消费释放事件。
- 用 Tab 聚焦图片，Page Up/Down 缩放，方向键移动视图，Enter/Space 恢复适应；Tab 继续切换其他控件。
- 放大倍率限制为 1～16 倍，平移会夹紧到图片边缘。更换图片或进入新的详情时恢复适应。
- 缩放和平移属于临时控件状态；存档和转场冻结其绘制图像时会保留准确几何，不将拖动句柄或设备资源写入状态。

自定义页面的图片视口支持 Stretch、Contain 和 Cover；九宫格用于普通装饰图，不适用于图片视口。图像绘制、焦点边框、命中区域与裁剪范围分别保持正确，不扩大按钮的输入区域。

变体名称参与正常文本提取与翻译，所有图片通过原生资产引用进入依赖闭包。正式编译、三项新增契约及 143 项完整逻辑基线通过，覆盖真实按钮、原生引用、解锁、绘制快照和跨页拖动释放；三套主题的原生详情页已刷新。未进行 GUI、GPU 或实机验收。
