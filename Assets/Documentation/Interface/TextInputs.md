# 玩家文本输入

页面输入框与玩家姓名输入共用游戏 UI 控件。文字仍写入绑定的剧情变量、页面字段或玩家输入状态；光标、选区和横向查看位置属于当前页面，不进入普通存档。

可使用左右方向键移动，Shift 扩展选区，Home/End 定位两端，Ctrl+A 全选。Ctrl+方向键按词组移动，Ctrl+Backspace/Delete 按词组删除。普通 Backspace/Delete 按完整字素删除，组合字符、emoji 和旗帜不会被切开。

指针点击放置光标，拖动选择范围；文字超出控件宽度时随光标横向查看。居中或靠右的输入框使用相同对齐位置计算点击。输入替换选区，达到长度限制时保留原有后缀，不会为了追加而删除后面的文字。

输入框为单行控件，提交文字中的控制字符不进入绑定。IME 组合期间不会执行文字移动、删除或确认；仅处理宿主明确提交的文字。当前视口尚未公开真实组合状态，实际 IME 仍属于引擎能力与设备验收边界。

截图和纯演出预览不包含光标/选区，也不会改变正在编辑的横向视图。游戏快捷键先服从文本焦点和模态界面；同一按键不会同时编辑文字和推进剧情。Tab/Shift+Tab 正向/反向导航。

文字测量复用实际游戏文字适配器，绘制仍由同一 VN 渲染提交完成。当前已有逻辑与绘制命令契约，没有进行窗口、字形后端或设备验收。
