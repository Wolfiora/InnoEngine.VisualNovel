# 复用界面组件

在界面设计器选中一个容器或控件，点击「将选中子树保存为组件模板」，会创建普通的 `.ivnui` 文档。保存后可以像页面一样编辑、检查绑定、预览并使用原生历史撤销。

需要复用时，在资源面板选中已保存的页面或组件，在目标页面选中一个容器，点击「插入所选页面 / 组件模板」。插件复制整棵元素树，重新分配控件、选项和文本身份，保留绑定、动作、样式及导入图片和字体的引用。字体或行内图片键冲突时拒绝整次插入，并说明冲突键。

插入结果是独立可编辑的副本。后续修改组件源文件不会自动覆盖已经插入的页面。通过普通页面文档事务撤销或重做插入。

内置资源面板的「组件」分类提供六种可编辑起点：阅读按钮、ADV 对话组件、剧情选项、阅读工具栏、文字速度设置行、确认页面。它们使用真实的游戏绑定与动作；对话和选项需要当前阅读上下文，确认组件需要实际确认页上下文。预览数据用于检查布局；实际交互应在对应游戏页面测试。

提取组件会将根布局归零并设为独立画布尺寸。插入后可调整尺寸、布局、动作与绑定；不会建立额外的组件文件格式或单独的运行时解释器。
