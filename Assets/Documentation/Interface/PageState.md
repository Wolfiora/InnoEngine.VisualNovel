# 不写脚本的页面局部状态

在「VN 界面设计」打开页面，在属性区展开「页面局部状态」，添加字段，设置名称、类型、默认值和生命周期。控件的绑定菜单会出现“页面”分类，不需要手填路径。

- **本次页面**：只属于当前页面访问，离开页面、开始新游戏或读档后恢复默认值，适合折叠区、临时输入和筛选。
- **游戏状态**：属于页面角色，关闭页面继续保留，明确进入普通存档和回滚；开始新游戏恢复默认值。

两类字段都与剧情变量、玩家设置、跨存档解锁分开。同名的剧情字段和页面字段互不覆盖。没有页面 Global 作用域；跨存档进度使用明确的剧情全局变量或收藏系统。

控件绑定方式：Toggle 接 Boolean，输入框接 String，滑块接 Integer/Number，选择器接标量或枚举，显隐/启用接 Boolean，位置/尺寸接数值。页面列表可作为重复行或选择器来源；每行提供 `item.value`、`item.text`、`item.index` 和 `item.enabled`。列表项是读取视图，不是可变 CLR 对象。

按钮动作选择「页面状态 · 切换 Boolean 字段」或「恢复字段默认值」，然后从菜单选择目标字段。状态动作使用明确的固定目标，避免把列表行参数误作字段身份。修改字段类型前须先处理不兼容绑定。删除被引用字段时会提示控件身份；可明确勾选同时清除绑定，再通过同一原生 History 撤销。

内置「可折叠状态卡片」使用上述机制：展开状态是临时 Boolean，标记是可保存 Boolean。提取子树会带上实际使用的字段；插入组件会重新分配控件与字段身份并重建引用，两份组件互不影响。

同一页面角色在不同主题中的同名字段，必须具有一致的类型、默认值、枚举成员和生命周期。主题可增加自己的字段，切换主题不会重新开始游戏。每页最多 256 字段，全游戏最多 4096 字段；文本限 32768 个 UTF-16 单元，列表限 4096 项。

页面定义和快照均使用引擎原生序列化。Runtime 自动落盘仍受正式根 codec 接口缺口限制；已配置原生 codec 的预览/宿主可使用同一存读档流程。140 项完整逻辑基线覆盖本批功能；未进行 GUI 或实机验收。
