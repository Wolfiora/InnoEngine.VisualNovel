# 游戏内提示说明

在界面设计器选中控件，展开「悬停与焦点提示」，填写纯文本说明、独立翻译 ID，或选择 String 类型的提示文本绑定。字面说明参与翻译提取和静态缺字检查；绑定读取当前页面或重复行的数据，读取失败时使用字面说明。提示不解析富文本标签，不会将玩家输入当作格式指令。

指针在同一控件停留 0.45 秒后显示提示；键盘焦点立即显示。禁用控件仍可通过指针说明原因，内置剧情选项绑定 `item.reason`。提示沿用控件的主题字体、前景和背景色，采用不透明底色，并按玩家字号重新测量；在画布边缘自动换边与裁切。很长的说明应改用正常详情页面，提示不是滚动阅读窗口。

提示只是绘制输出，不接收点击、改变焦点或执行动作。按下、确认、输入法组合、页面失去输入归属和选择器弹层会隐藏提示。目标或文字变化后重新计算悬停等待；稳定行身份保证列表重排不会沿用另一行的说明。存档缩略图排除提示和下拉弹层；提示计时和焦点不写入剧情存档。

复制控件会分配新的提示翻译 ID。保存组件时保留提示引用的页面字段；插入组件时重建这些字段身份，沿用同一原生文档和 Undo/Redo。String 以外的动态值会给出控件与绑定路径诊断；单条提示上限为 4096 个 UTF-16 字符，超出时明确报错。

已通过无图形输入、布局、翻译、缺字来源、原生元素往返与组件归属契约。真实字体塑形、GPU、输入设备和页面视觉效果尚未实机验收。
