# 页面层级与顺序

在界面设计器的页面树中选择非根元素，使用「上移一层」「下移一层」调整同一父元素内的绘制、排列和默认焦点顺序。展开「更换父元素 / 指定位置」，选择新父元素及从 1 开始的位置，确认界面中显示的原归属与新归属，再点击「应用层级变更」。

目标列表排除元素自身、其后代，以及会超过 64 层深度限制的父元素。一次变更是一项原生文档事务，可使用引擎 Undo/Redo；无效位置、循环或超深归属在修改前拒绝，不会先移除子树。

移动保留控件及后代的稳定 ID、翻译 ID、本地坐标、动作和绑定。横向/纵向/网格排列、父级裁切、相对锚点以及重复行上下文可能改变最终显示。不会自动重写 `item.*` 绑定或猜测新的绝对屏幕位置；移动后应检查画布及绑定诊断。页面根不能移动。装饰元素也可作为父元素，其行为仍由既有 UI 声明和布局规则决定。

已验证边界深度、同级双向重排、失败前原子性，以及原生选择、History、保存和重开。树拖放、多选对齐与完整 GUI 手势仍需继续实施；此入口没有经过本批实机验收。
