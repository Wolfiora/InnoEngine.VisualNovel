# 外边距、对齐与主轴分布

在元素属性的“外边距与自动布局对齐”中分别编辑左、上、右、下外边距。外边距在元素之外，不绘制也不接收点击；它参与容器测量、Fill 分配、网格行高和滚动内容高度。内边距仍是容器内部的统一留白。

横排、竖排和网格会为每个子项分配一个槽位。槽内水平/垂直对齐支持 Start、Center、End 和 Stretch；Stretch 与 Fill 都遵守最小/最大尺寸。绝对定位 Panel 继续使用位置、锚点和枢轴，外边距从它的可用父区域中扣除，不把自动对齐混入绝对坐标。

横排/竖排容器的主轴分布支持 Start、Center、End、SpaceBetween 和 SpaceAround。先扣除子项、外边距和最小间距，再分配剩余空间；SpaceAround 的首尾留白是相邻子项新增间距的一半。存在 Fill 子项时，剩余空间分给 Fill，主轴分布不再额外添加间距。滚动容器保持起点流式排列，以保持滚动和尾随含义稳定。

内容自适应测量包括子项外边距；横排先测量固定/内容子项，再给 Fill 子项分配剩余宽度。布局、文本测量、裁切和输入共用同一生产链。绑定、组件复制、主题运行副本与原生 History 保留这些属性。
