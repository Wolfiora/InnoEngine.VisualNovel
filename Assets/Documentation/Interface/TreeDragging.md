# 在界面树中拖动元素

拖动一个非根元素，到目标行上方四分之一表示「之前」，下方四分之一表示「之后」，中间表示「放入」。蓝色横线或边框表示实际目标；根只能接收子元素。

同级顺序调整直接作为一项引擎 History 操作提交。改变父元素时先选择源元素并填入「更换父元素 / 指定位置」，审阅后点击「应用层级变更」。本地位置、稳定 ID、动作与绑定都保留；新父元素可能改变堆叠布局、裁切与 `item.*` 数据上下文，工具不会猜测新的绑定或坐标。

不允许把根移走、把元素放入自己或子孙、超过层级上限，或使用已经修改的文档产生的旧拖动。拖动载荷只有面板 owner、文档、修订和源行编号，不保存 CLR 对象；重载后的面板会拒绝旧 owner 的载荷。

这使用引擎公开的通用拖放控件。File Browser 的原生资产拖放桥尚未向正式脚本导出，因此图片和音频仍通过已实现的所选资源按钮、匹配工具和原生资源表单关联；没有复制其私有载荷协议。

界面画布新增「预览高对比阅读」，使用实际游戏相同的绘制策略，不修改页面或主题。实际拖放和 GPU 显示尚未实机验收。
