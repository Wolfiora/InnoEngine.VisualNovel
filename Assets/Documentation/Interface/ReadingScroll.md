# 长台词与键盘翻阅

默认 ADV、NVL 和书信页面使用滚动区域显示长文本，文字揭示时跟随当前可见行。已揭示内容增高时继续跟随；手动向上查看后保留阅读位置，回到末尾后恢复跟随。

Page Up / Page Down 翻阅当前焦点所属的滚动区域；焦点不在滚动内容内时，使用当前页面第一个有效滚动区域。翻阅按键消费本次输入，不会同时结束对白或确认按钮，输入法组合阶段不触发这些快捷键。

阅读区域不允许翻到尚未揭示的空白未来。历史条目按实际内容高度布局，长台词不会固定截为同一高度。自定义页面可以在界面设计器中编辑滚动区域、文本内容高度、裁切与跟随绑定。

实际字体排版和多缩放视觉验收仍未执行；逻辑测试不替代玩家设备上的可读性检查。
