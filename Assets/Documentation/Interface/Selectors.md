# 选择器与数值控件

选择器使用真实类型的值，不把所有内容转成字符串。标题、选项名和存档摘要等只读信息用于文字显示；输入、开关、滑块及选择器的常用菜单只列出相应的可写字段。

## 枚举选项

1. 在「VN 界面设计」添加 `Selector`。
2. 选择游戏资产并点击“使用所选游戏的变量”，在“值绑定”中选择 Enum 变量。
3. 点击“替换为枚举声明选项”，生成类型正确的成员选项；可以修改显示名、禁用单项。
4. 或手工添加静态选项，配置显示文字与类型化的值。选项及其翻译 ID 保持稳定，复制控件时会分配新的身份。
5. 保存页面并关联到游戏。游戏校验会定位未声明变量、不兼容值类型或不可用语言。

选项文字会参与游戏翻译抽取。选择某项时才写入绑定；仅打开、浏览或取消下拉框不改变变量。界面内部的展开、滚动和焦点状态不进入剧情存档。

## 游戏语言

向导生成的设置页已采用语言选择器。它绑定“设置 · 语言”，选项来源为“可选游戏语言”。列表直接读取游戏翻译表中的语言名称和标识，不需要为每种语言写按钮动作。

下拉弹层最多显示八行，可以滚动。它在画布范围内选择向上或向下展开，不受父列表的裁切限制。键盘上下键或导航键移动到可用项，Home/End 到首尾，PageUp/PageDown 翻动可见范围，Enter/Space 确认。关闭后仍保留原控件焦点，点击弹层外也不会同时触发下面的按钮或推进剧情。

打开后直接输入文字即可按显示名或稳定 ID 筛选，忽略大小写；超过八项时显示搜索提示。Backspace 按完整字素删除，Delete 或 Ctrl+A 清空搜索；搜索最多 64 个字素。筛选结果保留禁用状态，没有结果时显示提示，不会写入空值。输入文字的同一帧不会同时确认选项。Escape 有搜索时先清除搜索，再次 Escape 关闭弹层，之后才交给页面返回。搜索、滚动、弹层和焦点都是临时状态，不写入剧情存档或截图快照。

动态选项按稳定 key 识别；列表排序变化不会把当前焦点悄悄变成另一个数组位置。普通 VN 游戏目前提供内置语言选项源；自定义宿主使用 `UiDataSource.ReadRows` 时，选项行需要 `text`、类型化的 `value` 和可选的 Boolean `enabled`。

## 滑块

绑定数字字段后，可以设置上下限和步长。步长大于零时，指针值会对齐步长；零表示指针连续调整，键盘按范围的二十分之一调整。Integer 变量保持整数，键盘自动步长至少为一，不会因拖动而被写成 Number。

获得焦点后用左右键改变数值。UiInputSnapshot 可表达输入法组合状态，组合时不改变数值或确认选项；当前正式宿主没有导出组合态，因此这里只验证域逻辑，不宣称实际输入法接入完成。

本批次只验证正式脚本编译和行为契约，没有验证弹层的实际美观、非整数缩放、手柄输入或大字号下的操作手感。
