# 在画布调整页面

打开 `.ivnui` 后，页面树、画布和属性面板编辑同一份页面。设计模式使用示例数据，不执行按钮的游戏动作；动画时间预览开启时不允许拖动布局。

## 移动与缩放

单击控件以选择。Panel 内的绝对定位子元素可以直接拖动，四条边和四个角上的手柄用于调整固定尺寸。锚点和枢轴保持原值，拖动左边或上边时，对面的边保持固定；最小和最大尺寸仍生效。

宽度或高度使用 Content / Fill 时，对应方向由自动布局决定，因此不会显示该方向的缩放手柄。在属性中明确切为 Fixed 后可以调整。横排、竖排、滚动列表和网格的子元素位置由容器计算，请使用层级顺序、容器间距和尺寸属性调整。重复列表的单个生成条目不能拖成独立布局，需要编辑声明模板。

网格可选 4、8、16、32 逻辑像素。开启吸附后，拖动位置或所选边吸附到网格；按住 Alt 临时关闭吸附。「显示网格」仅辅助创作，不写入游戏页面。缩放编辑器或预览画布不改变游戏的逻辑尺寸。

画布获得焦点后，方向键每次微调 1 逻辑像素，Shift + 方向键微调 10 像素。键盘微调用于精确定位，不套用拖动吸附。文字表单、其他面板和 Ctrl / Super 快捷键不会同时触发画布移动。

## 对齐

选择左边、水平居中、右边、上边、垂直居中或下边，再点击「应用对齐」。默认相对于父 Panel 扣除 padding 的内容区；关闭选项后相对于整个页面画布。对齐只移动所选元素，保留尺寸、锚点、枢轴、绑定和动作。

## 撤销与取消

一次连续拖动或连续按住方向键属于一项历史操作。释放后可整体 Undo/Redo；拖动过程中按 Esc 取消，恢复这次手势开始前的布局。切换文档、改变父元素、失去画布焦点或离开设计视图会结束当前手势，避免继续修改旧对象。

以上变换数学、原生历史、取消和保存已有无界面逻辑测试。实际鼠标手感、系统缩放和图形输出尚未实机验收。
