当前插件提供原生资产、共享图/剧本、引擎 History、分层舞台/角色、时间线/粒子、自有 UI 与当前系统页面、音频政策、翻译及收藏/回想。完整产品仍在实施，当前页面角色和三种配色不代表全部计划或三套完整主题。

Runtime 的引擎公开脚本接口尚无根序列化入口，因此本插件当前不提供正式游戏文件存档。内存解释器快照、调用栈、随机和变量恢复已通过契约验证。

源码许可见同目录 `LICENSE.txt`，第三方说明见 `THIRD_PARTY_NOTICES.md`。插件不包含其他功能插件或引擎原生后端的副本。
