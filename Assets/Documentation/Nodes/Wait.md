# 等待

节点图和剧本中的“等待”提供两种模式：

- 时间等待：设置有限、非负秒数，时间到后继续；零秒直接通过。
- 等待玩家推进：启用“等待玩家推进”，忽略时长。此时只显示可编辑的继续提示，不创建空对白或历史条目。

明确等待会停止当前自动阅读和快进。点击或使用确认键只释放这一处等待，同一次输入不会选择下一组选项或跳过下一句。舞台与其他并行演出仍按逻辑时间运行。

等待拥有真实的可恢复执行状态，可保存、读档和回滚；并行组里仍只允许一个分支拥有交互焦点。局部预览可以直接从此处开始，路线预览也可以把它作为精确目标；重放经过等待时自动通过，在目标处则停下供检查。

继续区域和提示均为三套主题中的普通可编辑 UI。`reading.waitingForAdvance` 表示当前显示明确等待，`reading.advanceVisible` 同时覆盖对白和明确等待的推进区域。游戏翻译抽取包含继续提示。

本功能使用同一剧情执行器与原生状态链。当前未进行实际窗口或设备验收。
