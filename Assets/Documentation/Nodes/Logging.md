# 输出日志与断言

在图或剧本的指令菜单中选择「调试 → 输出日志」。正文支持 `{变量标识}` 插值；`{{` 和 `}}` 输出字面花括号。变量选择、引用检查、搜索及跨章节复制使用与对白相同的规则。

日志支持 Information、Warning 和 Error。三者均继续执行下一条连线；需要在条件不成立时停止剧情，应使用「断言」。每条日志附带原始章节和节点标识，并写入引擎 Console，不使用独立日志系统。

默认「仅在预览输出」开启，正式游戏会跳过消息并正常继续。关闭此项才会在正式运行时输出。日志是即时诊断：读取之后的存档边界不会重放此前日志，回滚后重新走过该指令会再次输出。

日志不消耗随机数，不写剧情变量，不建立回滚屏障；可用于检查并行分支的确定执行顺序。它不能替代存档或可持久化剧情状态。
