# 在时间线控制音量

演出片段的 `Volume` 轨道控制逻辑音频槽位的音量乘数。它与位置、缩放等轨道共用一个片段、时钟、播放状态和命名标记，不另建音频时间线或播放后端。

1. 在时间线新增轨道，选择 `Volume`，指定一个独立目标槽，例如 `music`。
2. 设置 0～1 的关键帧。默认 1 表示保留原音量，0 表示静音；支持已有保持、线性、缓动和 Bezier 插值。
3. 在剧情的播放演出指令中，将该目标槽绑定到 `audio/bgm`。也可绑定已有音频指令声明的槽位，例如 `audio/rain`。
4. 用音频指令在对应槽位播放音频。先开始音量片段、再播放音频时，第一帧声音已经使用正确乘数。

常用槽位 `bgm`、`music`、`ambience`、`voice`、`sfx`、`ui`、`title` 和 `gallery` 可直接绑定。其他槽位需在当前游戏的音频指令中声明。逻辑槽位与 BGM/Voice 等混音分类不同，同一分类可以有多个独立槽位。

最终音量依次叠加音频提示音量/淡变、玩家总音量/分类、角色语音设置、语音压低 BGM 策略和时间线乘数。时间线不会覆盖玩家设置。交叉淡化时，同一槽位的新旧声音共同使用该乘数。

混合片段可以同时控制舞台和音量，但应使用不同目标槽。例如 `actor → character/guide` 的 X 轨道与 `music → audio/bgm` 的 Volume 轨道。系统明确检查目标支持的通道，Volume 不能绑定到镜头或角色。

片段结束后保留最后一个乘数，取消或被新的属性写入者替换后恢复未被轨道控制的音量。暂停、继续、跳转时间、等待完成和等待命名标记使用原有演出语义。减少动态效果会将可选视觉运动静态化，音量与包含音量的标记仍按真实逻辑时间推进。

保存和回滚从同一个舞台演出快照重建音量乘数，先准备静音候选声音与候选混音，再替换旧声音。失败保留原会话。玩家设置继续使用当前设置，不因回滚而恢复旧偏好。

时间线面板拖动只显示音量数值和纯演出，不重播声音或触发副作用；实际声音使用剧情预览。未配置音频输出适配器时，含音量的剧情演出明确报错。本批不播放真实设备声音；编译/逻辑测试状态以实施记录为准。
