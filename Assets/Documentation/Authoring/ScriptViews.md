# 剧本的三种视图

「剧本」页提供三种显示方式，始终使用同一份节点图、稳定节点 ID、连线、编译器和引擎 History。切换视图不转换文件、不重建节点身份，也不改变执行顺序。

卡片和紧凑模式可在正文中按 Ctrl+Enter（Super+Enter 同样可用）继续写同角色下一句。单行空对白直接按 Enter 也会继续。普通 Enter 保留段落换行；按钮始终提供同一操作。创建后定位新卡片并请求正文焦点，台词身份重新生成，旧配音不会被误复制。只有唯一 next 连线的对白允许直接续写，复杂连接需先明确目标。实际输入法组合与焦点交互尚未实机验收。

| 方式 | 适合的工作 |
|---|---|
| Cards 卡片 | 连续编辑对白的角色、姓名覆盖、正文和语音；关联所选角色；继续写同角色下一句 |
| Compact 紧凑 | 减少常用表单占用，集中快速编辑正文；其他参数通过完整检查器展开 |
| Proofread 阅读稿 | 查看姓名与去除格式标签的原文，保留作者变量占位；点击「编辑此段」回到对应卡片 |

任意指令都可通过「完整参数与连接」展开同一个检查器，编辑对白、选项、变量、演出及扩展指令的全部已实现参数。新增、复制、删除、片段归属、注释和连接操作仍走原有事务。复杂节点删除须明确确认涉及的连接。

每个执行段都标明片段。分支显示所有目标，汇合显示来源数量，循环显示稳定跳转目标；点击目标会共享选择并定位。不会递归展开循环，也不会把自由图改成另一棵语法树。

「继续写下一句」在当前对白的真实 next 边插入新节点，继承角色和阅读布局，使用新的台词 ID，清空上一句的配音与正文。原来的后续目标会保留。没有唯一合法 next 连接时，不猜测插入位置，使用完整连接编辑明确处理。

选中卡片后，可用「上移一句 / 下移一句」交换同一线性段内的相邻指令，或通过「移动到指定连线」选择明确的插入位置。预览展示三条连接的前后目标；跨越分支、汇合或片段时需要点击「接受连接变化并移动」。预览与应用均由正式编译器校验，非法并行范围、多个交互焦点和过期连接会拒绝，原图保持不变。操作保留节点、台词和原有连接身份，不移动图中的坐标；应用作为一个引擎 History 操作，可整体 Undo/Redo。

长章节按可见区域绘制，并以稳定节点身份记录已测行高。折返滚动、重排、复制和删除不会把其他台词的行高当成当前台词。窗口宽度或显示模式变化会重新测量。定位选中节点和诊断目标时使用同一行索引，不需要翻过固定页数。

节点图仍复用引擎画布的缩放、平移、拖动、多选和可见区域裁切；插件按文档修订号缓存节点几何。工作区也按原生文档修订号读取草稿，Undo/Redo、文档切换和重载都会更新相关派生数据。

无界面规模用例使用一个一万节点章节，检查投影、可见区、真实编译和入口执行，并记录当次耗时。这不是 GUI 帧率、首次项目导入或长期耐久验收；本批尚未操作实际编辑器界面。
