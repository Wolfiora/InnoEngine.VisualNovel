# 修改草稿后的预览

预览开始时准备一份独立的剧情、界面和资源声明。它读取游戏关联范围中已经打开的未保存文档，不自动保存，也不将后续编辑混进正在执行的故事。

修改相关章节、变量库、页面、角色、舞台或其他依赖后，预览提示具体变化来源。原始预览用例被修改或关闭时也会提示。临时用例设置和切换用例需要重新运行。旧会话可以继续检查，但路线录制和「将当前变量与舞台写入此用例」将停止；点击「运行此预览」用当前文档重新准备。

检测复用引擎文档修订、dirty 状态和资产 contentVersion。每次更新只轮询有限数量的来源，写回用例前核对整个捕获范围。打开或关闭一个没有变化的普通资源不会使预览失效。范围外资源的编辑也不会影响它；显式局部章节和原始用例另行跟踪。

Undo 不会自动重新认证已经失效的路线，应明确重新运行。停止预览会释放这些检查状态。此机制不冻结底层图片或音频设备，重新导入依赖后的实际 GPU / 音频表现仍需另行验收。
