# 快捷添加指令

在剧本或节点图区域，点击「添加指令」，或在没有编辑文字、拖动鼠标及打开其他菜单时按 Tab。输入名称、阅读/流程/演出等分类或英文指令 ID 搜索；方向键选择，Enter 创建，Esc 取消。

选中节点有唯一 next 连线时，可以选择「插入到当前 next 连线」：

- 对白、等待和其他线性指令会插入原路径，保留原来的后续目标。
- 在对白后继续添加对白，继承角色和阅读设置，正文与语音清空，台词身份重新生成。
- 选项会建立两条独立片段及各自的对白，并汇合到原后续目标。进入片段后直接继续写作，也可在属性中增加选项或修改目标。
- 并行会建立完整起点、两个等待分支和汇合节点，再接回原后续。
- 结束、返回、条件和随机等不满足上述规则的结构会独立创建，提示明确连接；不会因此丢掉原来的故事路径。

没有唯一 next 目标，或关闭插入选项时，新指令独立创建。公开入口和独立并行汇合点继续从章节/并行工具创建。资源或变量未绑定的指令会保留正常诊断，仍需填写参数。

一次创建及其内部片段、节点和连线属于同一项引擎 History，可整体 Undo / Redo。图与剧本共用这一操作，新增后会选择并定位同一个稳定节点。菜单打开期间文档发生变化时，应重新打开，避免对旧连接进行操作。
