# 分层角色动画

在「VN 角色设计」中选择姿势与部位，展开「部位动画」。每帧引用角色图像库中的一张图像，并有独立停留秒数；可添加、删除、上移和下移。每个部位最多 256 帧。删除最后一帧会关闭该部位动画，操作可通过原生 History 撤销。

- Sequence：一次播放或循环播放；一次播放结束后保持最后一帧。
- Blink：先保持当前姿势/表情图像，再播放短眨眼序列，然后回到静止图像。停留间隔可编辑。
- Talking：在作者的说话标记期间循环嘴型；结束标记后回到当前姿势/表情图像。这是预设帧切换，不进行音素识别。

在故事的舞台指令中，使用 BeginSpeaking / EndSpeaking 并选择同一实例名称。开始标记要求角色已经显示；找不到实例会给出源节点诊断。并行任务等待任一并取消剩余任务时，会关闭被取消任务拥有的嘴型标记。

呼吸是独立的轻微垂直变换。可以编辑幅度、周期及姿势范围内的锚点；默认锚点位于底部中间。角色镜像、旋转与演出轨道保持独立，呼吸围绕角色自身的坐标工作。每个部位还支持不改动源图像的颜色调节。

眨眼及循环序列可按稳定实例身份错开相位。动画按逻辑时间求值，暂停和拖动预览不依赖曾经绘制过多少帧。角色设计器可播放、暂停、重置或输入预览时间，并预览说话标记。

默认减少动态效果会关闭呼吸与可选帧动画；对需要保留的信息性动画，可以显式启用「减少动态效果时仍保留帧动画」。普通存档、回滚和转场的旧舞台保留帧资源、相位及说话状态。隐藏角色释放其动画状态。

角色实例名不能包含 `/` 或 `\`，以免产生部位所有权歧义。姿势复制会复制独立动画数据；编辑源资源不会改变已冻结的运行状态。
