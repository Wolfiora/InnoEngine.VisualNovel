# 使用当前未保存内容进行预览

剧情工作区先选择游戏上下文，再选择局部、路线或完整游玩方式。点击运行时，预览从引擎共享文档捕获当前未保存内容，不要求先覆盖源文件。

捕获范围是当前游戏的原生资源闭包，包括游戏设置、章节、舞台、角色、音频提示、演出、效果、主题、页面、本地化和收藏。主题中间接引用的页面也使用同一份页面草稿。未打开或未修改的资源继续从原生 Assets 获取，不额外打开编辑器文档。

其他已经打开且未保存的引用章节会通过生产编译器编译。无效章节报告章节/节点和原因，整个候选拒绝，不继续使用一部分新内容和一部分旧内容。修改期间的资源代际变化也会拒绝准备结果。

准备成功后才替换旧预览。运行中的预览拥有自己的数据和状态；继续编辑不会修改该预览，重新运行会准备新候选。输入清单显示捕获的资源数及使用未保存文档的数量。预览不会保存源文件、改变全局选择或把调试变量写回作品。

局部预览仍要求明确的初值和节点；路线预览仍使用记录的选择/输入。完整游玩不会把与所选游戏无关的当前章节加入游戏。路线目标需要属于所选游戏，独立片段检查使用局部预览。

预览指纹包含捕获的原生属性、资源身份/代际、入口及编译指令内容。预览存储仍独立于玩家数据。来源清单是临时数据，不创建第二套资产数据库或项目文件。

目前准备在调用线程执行，设置 10000 个资源、128 层依赖和 1 GiB 元数据预算；大型项目的增量准备、取消与性能验收尚未完成。实际 GPU、字体后端、音频设备及 GUI 操作未在本批实机验收。
