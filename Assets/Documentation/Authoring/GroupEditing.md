# 组选择、复制与删除

节点图与剧本使用同一个引擎画布选区。普通点击选择一个节点，Ctrl / Super 点击切换成员，Shift 按当前剧本投影顺序选择范围。工具栏和画布内的 Ctrl / Super+A 可全选。主节点用于检查器，组成员用于复制和删除；切换视图不会另存一份选区。

在图或剧本区域按 Ctrl / Super+C 复制当前组，Ctrl / Super+V 打开检查器中的粘贴审阅。输入控件正在编辑文字时，快捷键留给文字编辑。粘贴为节点和内部元素分配新身份，重建组内连线，并显示组外目标。跨章节的外部目标需要明确指定；无法解析的内容保留为 Missing，不能当作未分配资源忽略。

变量可以保留原 ID，映射到当前章节已有的兼容变量，或导入新 ID。映射到已有变量时使用目标的默认值和作用域。Boolean、数字、字符串、列表元素类型与枚举成员需要兼容；两个源变量不能合并成一个目标。变量表达式和文本占位会同时重写，转义的大括号和命令参数名称保持原样。缺失类型含有未知数据时，不推断其中的变量引用。

Delete 打开删除审阅。界面分页列出受影响连接和外部来源：普通单入单出线性路径可续接，分支、汇合和循环必须为每条来源选择新的目标或明确断开。断开后的不完整图继续显示编译诊断，不会被当成可运行内容。公开入口目标受保护，应先修改入口。

节点图也支持 Ctrl / Super 或 Shift 点击切换多选；拖动空白显示框选范围，并同步检查器主选项。Esc、失焦、隐藏图视图或切换文档会取消尚未提交的节点拖动和连线。缩放或平移时结束临时节点移动，避免重新显示视图后提交旧手势。

选择并行起点或汇合边界时，可先「展开完整并行组」。不能只删一半边界。审阅期间预览暂停；文档被修改后旧审阅失效。应用粘贴或删除是一项原生 History 操作，可整体 Undo / Redo。取消审阅不改图。
