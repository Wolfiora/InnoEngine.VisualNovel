# 剧情断点与单步

在 Visual Novel 工作区的「剧情预览」中选择游戏上下文与预览用例。在「断点」中，为当前所选节点添加断点；条件通过同一个可视化表达式编辑器设置。断点保存于 Editor scope 的 `.ivntest`，不会进入游戏存档。

运行预览后，可以应用修改后的断点、暂停、继续和单步指令。断点停在指令执行前；单步执行一条即时指令，或停在对白、选项、输入、计时等自然等待处。单步不会自动选择选项或填写玩家输入；继续后通过实际游戏界面交互。

条件读取被命中任务的局部、游戏与全局变量。随机条件不允许使用；变量缺失或类型错误时，调试器保留原位置并显示原因，不将剧情改成 Faulted。修复条件、重新应用并继续即可。

一个并行分支停住时，同会话的其他分支和舞台时间一起暂停。「调用栈与任务」显示稳定分支路径、当前位置、返回地址和调用者局部值。变量查看不要求当前扩展命令允许存档；修改只影响被检查的预览任务，并使路线录制要求重新建立明确前提。

「执行轨迹」显示进入的指令及实际经过的输出，点击可定位源节点，包括当前游戏明确关联的其他章节。调用栈、活动任务、断点和当前执行位置共用同一来源定位；来源包含未保存草稿。目标缺失、章节身份重复、只读源或来源变更时显示原因，不猜测同名节点。来源已改变需重新运行预览；定位失败保留原活动文档。

流程图以圆点显示普通断点、方块显示条件断点，并标出当前执行节点；「定位执行节点」只移动视角，不修改剧情。概览的视口框和选择标记复用同一图视图，可点击或拖动导航。轨迹保留最近 1024 项，界面显示最近 200 项；覆盖统计与存档分离。停止预览会释放对解释器的引用，新的预览拥有独立调试器。

尚未进行本批次 GUI、音频设备或完整热重载验收。当前工具不提供跨不可恢复命令的任意倒放；回滚遵循游戏本身的检查点和屏障规则。
