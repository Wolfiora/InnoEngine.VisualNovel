# 阅读布局

每句对白的「阅读布局」可选择 ADV、NVL、气泡、浮字或书信。它们使用同一类对白指令、文字节奏、已读记录、配音和输入规则；切换布局不建立第二套剧情数据。

| 布局 | 用途 | 创作参数 |
|---|---|---|
| ADV | 画面下方的一句对白 | 发言人、正文、配音及文字节奏 |
| NVL | 保留多句内容的整页叙事 | 勾选「从新的一页开始」清空当前页；历史记录继续保留 |
| 气泡 | 在画面指定位置显示发言面板 | 横纵位置和宽度比例 |
| 浮字 | 在舞台上直接显示文字 | 横纵位置和宽度比例，面板背景透明 |
| 书信 | 居中的书信或日记面板 | 发言人作为页首，长正文在页内滚动 |

新游戏向导生成的阅读页面包含全部布局。界面设计器可以继续修改各自的文字、背景、布局和绑定。既有游戏若使用自定义阅读页，需要自行添加对应控件；发布检查会提示缺少 `dialogue.pageText` 的 NVL 页面。

NVL 页内每句文字保存当时的变量文本。后来更改姓名、调试变量、切换语言或读档，都不会把已经写在这一页的旧句子改成新变量值。语言切换根据稳定台词身份重排整页，并复用每句冻结的替换值。NVL 页面与揭示位置参与保存和回滚；回滚改选会丢弃旧路线的页面内容。切换到其他阅读类型会离开当前 NVL 页，再次进入时开始新页。

NVL 页最多 200 句，总文字遵守一百万字符的排版上限。长篇内容应由作者明确分页。页内滚动默认跟随新增内容；玩家向上滚动阅读旧句子后会暂停跟随，回到底部继续跟随。书信页保留普通滚动行为。

气泡和浮字的比例基于游戏设计分辨率，宽度不会超出画面右边缘。底层是通用数值布局绑定：`dialogue.positionX`、`dialogue.positionY`、`dialogue.widthRatio`。勾选「按页面尺寸解释比例」时，绑定值相对于 UI 页面的设计尺寸计算，因此不会被游戏输出的缩放重复缩小。布局绑定也支持像素值、游戏数值变量和列表项数值，也可以在界面设计器中选择；无绑定时使用原来的手动位置与尺寸。

这些布局不依赖 Canvas 或 Rendering2D。当前气泡使用作者指定的位置，尚不自动跟随某个角色的头部。实际皮肤美术、宽高比和大字号效果仍需后续实机验收。
