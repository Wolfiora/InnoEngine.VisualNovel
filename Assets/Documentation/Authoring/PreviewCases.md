# 带明确初始条件的剧情预览

工作区的「剧情预览」读取一个明确选定的游戏定义，编译当前未保存的章节，并创建独立的正式 Player 会话。舞台、声音策略、阅读、选项、输入和游戏页面采用正式运行链。玩家存档和全局进度不会作为默认初始条件，也不会被预览写入。

先在 File Browser 选择 `.ivnproject`，点击「使用所选游戏作为预览上下文」。可以直接调整临时用例，也可以创建 `.ivntest` 保存预览条件。用例文档使用引擎 History、原生保存和重载机制，属于 Editor scope，不进入正式 Player 内容。

| 方式 | 起点与语义 |
|---|---|
| 完整游玩 | 从游戏配置的真实章节和入口开始，也可以显式选择另一个公开入口 |
| 局部预览 | 从当前章节中指定的节点开始；变量采用明确的用例值与声明默认值，舞台采用游戏初始舞台或用例快照 |
| 路线预览 | 从明确入口按记录的选项和输入重放，到当前章节中的对白、选项或输入目标时停止 |

局部预览不会猜测此前的调用栈、分支和角色状态。用例中的变量在第一条指令之前写入，舞台快照也在第一条演出指令之前恢复。不能从并行子任务内部建立非法入口；该限制由正式编译器检查。

推荐先用「完整游玩」实际选择和输入，再点击「将实际试玩路线写入此用例」。记录只包含正式会话真正接受的选项、提交文字或取消操作，不要求手抄 ID。循环回到同一节点时，记录还保留确切的目标交互序号，重放不会错误停在第一次经过的位置。反复经过同一个输入节点可以使用不同的按序输入。

路线数据使用稳定选项 ID，不依赖显示文字；高级表单也允许调整这些记录。条件改变后，记录的选项如果缺失、隐藏或禁用，预览会停在可检查的状态并说明缺少哪一步。路线执行有逻辑时间和更新次数预算，可以取消；不会阻塞编辑器等待无限循环。当前路线目标限定为交互节点，即时演出节点可使用局部预览，尚未把这一限制描述成完整断点调试。到达目标后暂停，点击「从当前状态继续游玩」恢复普通时间与交互。

画布使用正式 UI 并接收指针及键盘导航。编辑器公开接口尚未提供画布中的完整输入法组合消息；玩家文字输入同时提供原生编辑器测试输入框，提交仍调用正式会话。真实 Game 视图的输入适配另行验证。

可以暂停预览时间、单步时间、定位当前节点和修改会话变量。变量修改默认仅影响此预览；只有点击「将当前变量与舞台写入此用例」才更新用例。调试改值或读档替换状态后，不能再把这段会话记录宣称为从原初值可重现的路线，需要保存局部初值或重新运行。切换到其他工作区页签会暂停预览声音，停止、关闭或重载时释放会话、声音与预览资源。

自定义命令继续遵守预览能力限制。当前显式注册的扩展可由高级宿主传给 `NovelPreviewSession`；工作区自动发现自定义命令仍依赖尚未公开的类型发现契约。没有预览权限或具有外部副作用的命令不会被默认执行。
