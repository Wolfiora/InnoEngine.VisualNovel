# 配音管理

在「VN 配音管理」中依次选择游戏定义和章节。先导出配音稿，让录音文件名采用稳定的台词 ID；文件可以有统一前缀，例如 `zhCN_`，在匹配时填写相同前缀。

录音放在项目 `Assets` 内的明确文件夹中，填写相对于 `Assets` 的路径后预览匹配。每批最多 10000 个文件，预览按 50 条分页。台词 ID、同名多录音、缺失录音、未成功导入和资源 ID 冲突均会显示原因。默认保留已有配音；明确启用替换并重新预览后才会替换。

应用审核结果时，插件先确认台词和音频仍与预览一致，再通过引擎原生导入创建 Voice 提示。章节语音绑定与游戏音频库在一个引擎 History 事务中修改，两个视图共享结果；新建的音频提示是独立资源，不因撤销引用而删除。

选择配音语言后，原文批次关联章节指令；目标语言批次读取已复核的当前译文，写入翻译表中的语音关联，保留译文、复核状态和原文指令。译文缺失、为草稿或原文已更新时不会自动绑定。修改语言、文件夹、前缀或替换策略后需要重新预览。

点击「保存章节、翻译与游戏」保存相关文档后再运行。配音稿和匹配清单导出到 `artifacts/Exports`，采用带引号的 CSV/TSV，包含语言列，可保存 Unicode、多行和引号。清单不替代原生剧情资产。

预览同时记录当前原文、译文、语音和音频代际；这些内容变化后必须重新匹配。原文与语言版本批次已通过正式编译和原生逻辑验证。录音试听与实际播放不属于本批次验收。
