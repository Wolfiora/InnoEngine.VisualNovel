# 已读记录与快进范围

已读属于跨存档全局进度。台词完整揭示后才记录；回滚和普通读档不会撤销它。默认快进只跳过已读，遇到未读、选项、玩家输入或脚本屏障会停止。

读取身份使用原始章节、稳定台词 ID 和当前语言尚未插值的作者原文。玩家改名、变量数值变化不会把同一台词重新变为未读；作者修改原文或翻译、重新分配台词 ID 则会产生新的内容身份。不同翻译各保留自己的阅读记录，切回已读语言仍可继续快进。

图的布局不影响已读。复制对白会重建台词身份，以免把另一句误判为已读。历史中仍显示当时实际呈现的插值结果，存读档恢复冻结参数，不会重新从当前变量拼出旧台词。

这不提供旧数据格式或旧算法的迁移。玩家进度的生产自动保存继续遵循 Runtime 原生序列化接口边界；预览使用独立临时存储。
