# 章节搜索、备注、标签与书签

在节点属性中展开「作者备注、标签与书签」。备注支持多段文字，标签每段一个；勾选书签后可在工作区「搜索与书签」中筛选。

搜索是当前章节的普通文字查找，不执行表达式。可查对白、姓名、台词身份、节点身份、选项、资源键、调用目标、系统动作参数、变量表达式、备注与标签，不区分英文大小写。未知扩展节点仍能搜索身份和作者备注，原始设置保持不变。

输入搜索文字、切换书签筛选或点击刷新会生成结果快照，每页 40 项。修改章节或撤销重做后点击刷新更新。点击结果使用共享节点选择，可回到图或剧本定位；如果节点已删除，会显示失效状态。

备注与书签保存在同一原生图的附加数据中，不是第二份剧本。复制节点会保留备注和标签并生成新节点身份，Undo/Redo 使用引擎 History；保存重开保留标注。它们不增加执行连线，也不改变对白或分支行为。

当前入口针对已打开章节，尚未提供跨项目全文索引和全项目替换。此批次没有 GUI 或易用性实机验收。
