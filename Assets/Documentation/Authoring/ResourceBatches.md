# 批量创建资源副本

“VN 内置资源”的批量勾选跨页和筛选保留，可一次选择当前筛选内的全部可编辑资源。图标是普通不可变图片引用，不加入这一批参数资源复制。

点击“批量创建可编辑副本”后，每次编辑器更新处理一个所选资源。主题连同它的页面作为一项；新主题重新建立页面引用，多个角色指向同一源页面时，继续指向同一个新页面副本。资产身份和舞台/角色/音频/演出资源键均独立。

进度显示所选资源的完成数，并分页列出实际已创建资产；点击输出可定位并打开对应原生文档。复制只写普通 `Assets/Game/Resources/`，不修改安装包。

“停止批量复制”阻止下一项。已经提交的资产会保留并列出，可继续使用；原生导入和单个主题不能中途抢占。失败也保留已提交输出，包括某主题在失败前已提交的页面，不能把部分成功说成整个批次成功。源身份、路径或内容修订变化时停止，请重新选择后运行。

批量与单个复制复用同一原生复制服务，不另建资产库或持久化格式。面板销毁会停止尚未执行的项目。创建的资源仍需在游戏定义或设计器中显式关联，批量复制不会自动改变现有游戏。
