# 存档缩略图

Scene 宿主配置原生存档服务后，会同时关联同一生产渲染链的截图端口。手动、快速和自动存档先冻结剧情状态与阅读界面，再等待 GPU 回读，最后原子提交包含状态与 PNG 的完整数据包。存档菜单本身不会成为阅读缩略图。

截图期间正常显示处理状态。失败、取消、超时或游戏被替换时，最后有效存档仍保留。自动存档在选项进入的当刻捕获画面与状态，不能等其他 IO 完成后再截取已经变化的故事。队列有明确数量上限，每个请求有 30 秒期限，关闭游戏或替换 Pipeline 会结束请求。

默认截图为 320×180，设计画面按比例适配，空余区域填黑。颜色从线性预乘透明度的 GPU 结果转成标准 sRGB RGBA PNG；回读会处理实际行距、上下原点和透明度。该 PNG 是图片格式，剧情状态仍完全使用引擎原生序列化。

存读档页面中的图片控件绑定 `item.thumbnail`，同一字段在界面设计器的图片绑定菜单中可选。读取损坏图片时保留存档元数据和错误处理，不把损坏图片当成可执行内容。生成图像不写入资产数据库；纹理由当前渲染 owner 释放，不可见截图纹理会及时退休。

GPU 绘制目标与回读目标分开：先渲染至可绘制图像，随后用公开 Copy Pass 复制到独立传输纹理，再在后续帧调用公开回读服务。缺少纹理复制/回读能力时报告错误，不假装生成了一张有效截图。

PNG 格式、引擎独立 PNG 导入、无设备 RenderGraph 校验、状态与图片同一边界、失败保留原包、过期结果、生成图片绑定和队列退休已有逻辑测试。**真实 GPU 回读、截图观感和设备性能尚未实机验收。** 原生 Runtime codec 的宿主接口缺口仍然单独存在，见实施状态。
