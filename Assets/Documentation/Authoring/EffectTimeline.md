# 屏幕效果参数轨道

演出片段可以同时控制舞台、UI、音量和屏幕效果。效果目标使用 `effect/实例ID`，对应剧情中「设置 / 淡变屏幕效果」的实例。在剧情演出节点指定游戏后，可直接从效果实例列表选择目标。

| 通道 | 适用效果 | 范围 |
|---|---|---|
| EffectStrength | 全部效果 | 0～1，乘以当前效果强度 |
| BlurRadius | 模糊 | 0～32 设计像素 |
| VignetteRadius | 暗角 | 0～1 |
| VignetteSoftness | 暗角 | 0.001～1 |
| Saturation | 颜色调整 | 0～4 |
| Brightness | 颜色调整 | −1～1 |
| Contrast | 颜色调整 | 0～4 |
| PixelSize | 像素化 | 1～512 设计像素 |
| LetterboxRatio | 遮幅 | 每条遮幅占高度的 0～0.45 |
| AberrationPixels | 色差 | 0～32 设计像素 |

除 EffectStrength 外，轨道数值直接指定参数。未被轨道控制的参数继续使用预设。参数轨道不改写效果资源，也不会覆盖原来的强度淡变时钟；取消片段后恢复预设参数与原来的强度状态。

先在剧情中创建效果实例，再启动绑定到该实例的片段。也可让轨道先开始，实例出现后会立即使用当前逻辑时刻的样本。移除效果本身不会重复创建它，也不取消同一片段中的其他演出；重新使用相同实例 ID 时会使用当前轨道样本，需要停止时明确取消片段。

同一实例若在不同剧情位置使用多种效果机制，只有这些机制共有的通道可以绑定。例如模糊与像素化交替使用同一实例时，只能绑定 EffectStrength；分别使用两个实例即可独立控制半径与像素尺寸。不兼容目标和参数会定位到演出剧情节点。

在时间线选定舞台或 UI 页面作为明确初始状态，再选择一个屏幕效果，指定预览实例并绑定轨道。拖动时间会用真实效果帧与绘制链组合图像，不执行剧情指令、解锁或存档。

暂停、跳时、循环、标记、冲突替换、保存恢复与回滚全部沿用同一演出状态。减少动态效果遵循片段策略；关闭闪烁仍会屏蔽闪白，参数轨道不能绕过玩家设置。实际 GPU 图像与显示效果暂未实机验收。
