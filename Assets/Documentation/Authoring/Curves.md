# 时间线插值曲线

在 VN 时间线中选择关键帧，可以选择线性、保持、平滑、缓入、缓出、缓入缓出或 Cubic Bezier。插值规则作用于当前关键帧到下一个关键帧的区间。

Bezier 面板的横向代表时间，纵向代表属性进度。两个控制点限定在 0–1 内；拖动控制点和数值输入都通过同一原生 History 编辑事务。Esc 取消整次拖动，结束拖动提交一个历史操作。

运行时先根据曲线横向求参数，再计算纵向进度，不把时间直接当作 Bezier 参数。因此不对称时间控制点也能按画布预览求值。求值由逻辑时间决定，拖动预览不会执行剧情解锁或存档等副作用。

曲线随片段原生保存，改关键帧值或移动时间时保留控制点。运行实例冻结片段副本，后续编辑源资产不会修改正在播放的快照。当前内置 20 个动作已经按曲线数据声明重新生成。
