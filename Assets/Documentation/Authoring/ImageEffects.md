# 转场与屏幕效果

在「VN 转场与屏幕效果」中创建 `.ivneffect`，选择屏幕效果或转场，编辑参数并拖动逻辑时间预览。选中内置资源后先创建项目副本，再修改；不要编辑插件安装目录。粒子使用独立的「VN 粒子设计」。

新建游戏会关联 12 个转场、10 个屏幕效果和图像处理材质。已有游戏可以在「VN 游戏设置」附加效果资源；图像处理材质的 Shader 必须使用 `NovelPostProcess.ishader` 的 `inno.vn.post` 契约。原有精灵/文字材质继续使用 `NovelSurface.ishader`。

## 在故事中使用

- **屏幕效果**：设置或渐变指定实例的强度；可选择包括游戏 UI、叠加顺序和等待完成。暂停、恢复、完成、移除、等待使用相同实例 ID。同名请求明确替换旧效果；渐变从当前强度开始，换预设时从零开始。
- **转场**：开始时冻结旧舞台，可以同时切换到另一舞台，也可以紧接着添加角色或舞台操作形成新画面。勾选等待完成后，编译器在同一源节点处产生显式等待，不改动作者的图和节点身份。
- **Group**：只处理指定舞台分组，精确目标可留空或使用舞台层 owner。其他分组继续显示当前画面。
- **Stage**：处理舞台与装饰底层，UI 保持实时交互。
- **Output**：处理包括 UI 的完整输出，保存切换前实际准备显示的 UI。首次渲染前没有旧 UI 时使用透明空画面。

转场一次只有一个活动边界，新请求明确替换旧边界。完成保留新舞台；取消恢复捕获的旧舞台，**不会撤销剧情变量、解锁、存档或脚本副作用**。需要撤销剧情时使用回滚。并行任务取消会完成其拥有的转场，保留已经提交的新舞台。

## 机制与恢复

转场支持经色彩淡化、交叉溶解、方向擦除、程序遮罩、推移和虹膜。遮罩提供固定种子的颗粒、棋盘、百叶窗和菱形。屏幕效果支持双向模糊、暗角、灰度、颜色调整、像素化、闪白、遮幅、棕褐、反相和色差。

时钟、暂停、渐变起终值、旧舞台、转场进度和输出级旧 UI 都进入原生会话快照。旧 UI 只保存几何、文字及资源身份，不保存控件实例或 GPU 对象。恢复会先验证整个候选，缺少资源或 UI 边界不匹配时保留当前游戏。

玩家的「减少动态效果」直接完成渐变和转场；「允许闪烁效果」关闭时不绘制闪白，并跳过具有中间色彩的淡化转场。两项设置独立于普通存档。装饰底层的 `behindStage` 不接收输入，也不会挡住角色或转场。

渲染使用公开 RenderGraph 和自有 Shader，不依赖 Canvas、Rendering2D 或具体后端程序集。中间图像采用预乘透明度；原始精灵与字形使用普通透明度提交。转场与模糊的原始图像依赖均显式进入渲染图。

逻辑和快照验证已经通过。新增设计器的实际操作、GPU 视觉、不同 DPI、颜色空间和真实设备性能尚未实机验收。
