# 流程图导航

流程图顶部可将全部节点或当前选择居中，保留当前缩放级别。选中多个节点时按它们的共同边界居中。居中与浏览只调整引擎现有画布视角，不修改节点位置、执行边或选择成员。

「导航缩略图」默认开启，在右下显示章节范围、节点分布、当前视口及选中节点。点击或按住拖动可将主视口移到对应位置；空白小画布会自动隐藏缩略图。节点数量很大时，分布合并到有界网格中显示，实际故事身份和连线保持不变。

缩略图拥有自己的指针捕获。失焦、Escape、切换文档或文档修订会取消导航拖动；在缩略图上开始操作不会同时选中或移动底层节点。中键平移和滚轮缩放继续由主画布处理。

该导航入口使用公开 GraphCanvasState、GraphCanvasLayout 和编辑器绘制 API。当前没有实际鼠标、缩放显示或 GUI 验收，不能据此宣称大工程帧率达标。
