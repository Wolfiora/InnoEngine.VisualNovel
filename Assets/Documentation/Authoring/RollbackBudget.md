# 回滚快照的预算

默认最多保留 100 个边界，游戏定义的检查点数量可以调整。宿主配置原生 codec 后，回滚快照只保留原生编码缓冲区，默认载荷上限 64 MiB；原生场景中 VN 玩家组件的 `rollbackBudgetMiB` 可直接设置，0 表示禁用保留。预览已有 Editor 原生 codec，会使用同一机制。

预算只计算本会话保留的原生快照载荷，小型边界元数据另受数量上限限制。它不是整个进程、当前游戏状态、资源库或 GPU 的硬内存上限。

预算不足时先淘汰最旧快照。单个快照已经超过整个预算时略过该位置，但不会伪造存储成功，也不会停止正在游玩的故事。更早且仍有效的点依然可用。编解码失败保留当前游戏；编码失败的说明显示在预览中。提高预算只能保留后续新点，不会重新生成已经淘汰的过去。

存档恢复和回滚都保留当前玩家的语言设置。快照单独记录该边界实际使用的显示语言，避免并行子任务的配音或缩略图错误使用父任务上一句的语言。全局已读与解锁仍不随回滚撤销。

Runtime 自动获取原生 codec 尚受引擎公开 API 限制。未配置 codec 的会话继续使用数量上限，并明确把字节占用报告为未知；不会用一个估算数宣称已经满足字节预算。高级宿主可通过 `NovelSessionOptions.checkpointCodec` 与 `rollbackByteBudget` 接入既有原生服务，不需要另一种存档格式。
