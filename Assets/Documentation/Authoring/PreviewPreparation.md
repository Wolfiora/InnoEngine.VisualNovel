# 准备、取消与替换预览

完整预览和紧凑预览先准备候选资源，再创建实际 Player 会话。准备期间显示当前资源/章节和已捕获资源数；这不是完成百分比，因为依赖闭包会逐步展开。

资源捕获、依赖遍历和章节编译之间会让出编辑器，可点击“取消预览准备”。再次运行会释放旧候选；修改用例、关闭或保存来源文档、热重载和工作区销毁也不会让旧候选迟到替换当前预览。准备不保存源文件，不另开文档，也不改变共享选择。

先前预览在准备期间暂停，保留自己的会话。只有候选成功创建后才替换它；取消、草稿变化或编译失败会保留原会话。提示中包含失败资源或章节/节点，修正后重新运行。

候选使用原生序列化捕获资源和未保存文档；最终在同一个编辑器更新中核对全部捕获的身份、内容修订和文档状态，随后发布候选，防止接受准备期间改变的输入。预览用例的变量、舞台和路线在开始时原生复制，之后的表单编辑不会污染候选。

这是分步准备，不是把引擎资产 API 放到后台线程。单个原生属性捕获、导入或章节编译，以及最终核对仍不可抢占；大型单章仍可能超过每次更新的目标耗时。当前不宣称 100ms 或十万句工程的交互指标已经通过。
