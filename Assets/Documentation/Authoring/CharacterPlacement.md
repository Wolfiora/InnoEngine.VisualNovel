# 角色站位与安全区

在角色显示指令中，选择对应角色资源后展开「快捷站位、相对锚点与安全区」。可以采用左侧、中央、右侧，或填写自定义相对位置。默认将角色范围的底部中心放到安全区底边。

参考画布可从明确选择的游戏定义或舞台读取，也可直接填写宽高。安全边距按设计像素计算。相对 X / Y 为 0 时对齐安全区起点，为 1 时对齐末端；允许负数或大于 1，用于明确的画外站位。

九点角色锚定使用实际可见姿势范围，包括表情部位显隐、局部偏移、裁剪、镜像和旋转。计算不包含呼吸时钟。应用只写入角色实例的 X / Y，保留本地枢轴、缩放、旋转和透明度，并沿用原生剧情文档 History。

计算在点击应用时完成，结果是普通剧情变换；没有隐藏的位置系统或另存一份运行顺序。之后修改角色资源或参考画布时，应重新应用需要调整的站位。全隐藏或零范围姿势会显示原因，不改变节点。

舞台画布可显示构图安全区和左、中、右参考线，边距可精确调整。参考线只用于创作，不裁剪游戏画面，也不改变角色的运行位置。站位工具与舞台画布各自保留临时参考设置，应使用相同宽高和边距进行构图。
