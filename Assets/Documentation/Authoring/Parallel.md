# 并行演出

添加「并行演出」会创建普通图节点组成的起点、两个等待分支和所属汇合点。在线性连接上添加时，会接好前后路径；图与剧本操作同一份节点和连线。

每组 2～16 个分支，整个会话最多 64 个活动子任务，最多嵌套 8 层。属性中可以添加分支、预览并确认删除分支及其内部节点、选择等待全部或任一完成。外部引用未处理时删除会拒绝。复制完整组会重建起点、汇合点和分支端口的身份。

分支支持对白、选项、姓名输入、等待、条件、随机路径、断言、变量赋值、舞台、音频、演出及具有安全声明的自定义命令。每组至多一个分支拥有交互焦点，其他分支可以继续演出；两个分支都包含交互指令时编译会定位错误。姓名输入也计入变量写权限。不同分支可以写不同变量，Game、当前调用的 Local 与 Global 作用域由父会话共享。同变量竞争在编译和执行前都会拒绝。解锁、页面切换及跨章节调用仍放在汇合后。每条执行连接必须留在所属范围内；同一音频槽、演出实例或即时舞台目标不能由多个分支同时取得写权限。交互分支保留读取配音槽，不能让另一个分支争用它。

每次逻辑更新按列表中的稳定分支顺序执行，不创建工作线程。可用“提前执行 / 延后执行”改变顺序，保留端口身份和所有连线；后执行的分支能读取前面已提交的赋值。等待全部时，所有子任务到达所属汇合点才继续；等待任一时，完成后取消尚未结束的任务，立即释放它们启动的持续音频、动画和粒子。已经提交的即时舞台修改和变量赋值保持，取消不是反向播放。

快照保存每个子任务的游标、等待、随机、扩展状态与资源身份，恢复后继续剩余等待，已完成的赋值不重复执行；子任务变量快照必须匹配所属父作用域，否则拒绝候选并保留当前会话。Global 变量仍不随普通读档或回滚撤回。并行失败包含分支和源节点位置；无等待的循环仍受即时指令预算约束。

上述语义已有域和真实会话音频替身测试；没有实机音频、时间线手感或图形验收。

交互分支使用正式游戏的同一套对白、选项、输入、已读、自动阅读、历史和 UI 绑定。一次确认只结束当前交互，不同时推进下一句；文字速度只影响文字揭示，不改变其他分支的等待时间。存读档和历史回滚可以停在分支内部，路线录制保存实际子节点与整个会话的访问次序。NVL 进入分支时继承当前页面，只有完成的交互分支在汇合时交回页面；被取消的页面不会并入后续正文。等待任一取消仍在说话的分支时，会停止它拥有的配音。
