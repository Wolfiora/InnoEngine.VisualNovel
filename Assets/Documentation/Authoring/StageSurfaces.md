# 舞台图层和角色部位的图像处理

舞台设计器的图层与角色设计器的部位都有“源图、裁剪、混合与遮罩”折叠区域。它们使用原生图像资源，修改参数不会改写 PNG/JPEG。角色的表情与序列帧继续共用此部位的图像处理参数。

## 源图和裁剪

源图区域采用 0～1 坐标。例如 `(0.5, 0, 0.5, 1)` 取原图右半边，并将它映射到部位原有尺寸。适合从已制作的图集中选择子图。

保留区域也采用 0～1 坐标，但它裁去对象本身的局部几何。例如保留左半边使用 `(0, 0, 0.5, 1)`，对象留下的部分仍在原来的位置，不会拉伸到原宽度。源图和保留区域按顺序组合。宽度或高度为零时不产生画面。

枢轴使用对象本地像素。放置坐标表示该枢轴最终所在的位置，然后围绕枢轴缩放、镜像与旋转。默认枢轴 `(0, 0)` 沿用左上角放置。角色部位枢轴和剧情“显示角色”的整个角色枢轴可以组合，舞台时间线仍围绕该实例的放置位置演出。

## 混合

- Normal：按透明度覆盖背景。
- Add：在线性颜色空间相加预乘颜色和覆盖度，并在 1 处截断，适合光斑与发光叠层。
- Multiply：重叠部分相乘，保留双方未被覆盖的区域，适合阴影和色调叠层。

计算使用已有 VN 图像合成材质，结果保持预乘透明度。普通未遮罩的 Normal 图层继续使用直接绘制链。混合在当前舞台背景上求值，包含位于舞台下方的页面内容，不影响上方的游戏 UI。针对图层组的转场会先将选中组隔离到透明画布，再对整组进行转场；组内非 Normal 混合以该组自己的背景为边界。

## 遮罩

选择已经在资源库中的图片，或在原生 File Browser 选中图片后点击“使用所选图像作为图层/部位遮罩”。遮罩覆盖完整、未裁剪的本地尺寸，随同对象变换；它不会采用源图的图集区域。保留区域会同步裁剪遮罩。

Alpha 取透明度；Luminance 取线性亮度乘以透明度；InverseAlpha 和 InverseLuminance 分别取其补值。遮罩先改变图层的颜色与透明度，再参与混合。遮罩自身不作为可见图层绘制，不受被遮罩图层的颜色影响。

一个舞台最多同时保留 48 个含遮罩或非 Normal 混合的图层，以限制图像合成图的深度和中间资源。普通图层仍受既有的 10000 层状态预算约束。超限会明确拒绝候选，不替换正在显示的状态。

## 保存和检查

源图、裁剪、枢轴、遮罩身份与混合模式都进入原生资产、Undo/Redo 和会话快照。缺失遮罩、越界区域和未知模式会导致验证失败；读档仍先准备完整候选，失败保留原会话。语言图片映射也作用于遮罩；应为每种语言准备形状相符的遮罩。

新游戏向导会生成需要的图像合成材质。手工配置游戏时，使用遮罩或混合模式的游戏必须关联该材质；发布检查会指出遗漏。

本批只做逻辑、正式 API 编译和离线 Shader 检查。实际 GPU 颜色、滤波边缘与设计器交互尚未实机验收。
