# 批量修改舞台图层

在舞台设计面板展开“批量修改舞台图层”，按名称或稳定 ID 筛选，再勾选需要一起修改的图层。列表每页 40 项；切换筛选或分页保留勾选，切换舞台文档清空选择。这个勾选集独立于单层检查器与画布主选项。

横向/纵向偏移和旋转对各层相对增加，缩放以原值倍乘，保留镜像和枢轴。显隐、不透明度、颜色和合成分组只有开启对应覆盖项时才修改；图层身份、源图/遮罩、尺寸、裁剪、组内顺序和未勾选图层保持原值。

“应用到全部勾选图层”包含其他筛选页的勾选。全部目标先完成约束检查，失败时不留下部分修改。更改可以作为一项操作撤销或重做，保存后仍是普通原生舞台资产，预览与游戏消费同一份数据。

位置、缩放与旋转沿用单层画布的约束。被移除的选择、重复身份、无效数值和超出坐标范围会拒绝操作。只读安装资源先从内置资源面板创建项目副本。

已有纯逻辑、原生状态恢复、真正的 History 与保存契约；面板键鼠操作尚未实机验收。
