# 时间线关键帧组编辑

演出时间线使用同一份 `.ivnclip`，不创建另一套动画数据。时间缩放和可见起点只改变创作视口；「完整片段」「定位播放头」用于恢复导航。每页显示最多 12 条轨道，可切换查看。

点击关键帧选择；Ctrl 切换选择，Shift 追加。在轨道空白处拖框可以跨轨道选择，按住 Ctrl 或 Shift 保留原有选择。拖动选中关键帧会一起移动选区，保持帧间距和各轨道归属。吸附作用在拖动的主关键帧，Alt 暂停吸附；边界约束作用于整组选区，不会把多帧挤到片段端点。

整组移动、复制和删除也有数值入口。目标时间与保留关键帧冲突时默认拒绝，原有数据保持有效；必须明确勾选允许覆盖才会替换。删除某轨道的最后一个关键帧必须允许同时移除空轨道。同步标记不跟随关键帧组移动，可单独拖动或填写时间。

所有拖动样本从冻结起点计算，使用引擎 History 合并为一项操作。Esc 或失去窗口焦点取消拖动；撤销、重做、文档切换和重载不会保留旧代际手势。拖动只对演出求值，不触发存档、解锁、剧情指令或外部脚本。

逻辑契约和原生保存/History 已列入验证流程；实际鼠标操作、缩放后的显示和 GPU 预览仍需后续实机验收。
