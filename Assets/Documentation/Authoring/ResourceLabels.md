# 资源分类与标签

从引擎 Authoring 菜单打开「VN 资源整理 · Resource Labels」，创建一份 `.ivnlabels` 创作文档。在 File Browser 选择已导入的图片、音频或其他原生资源，然后点击「收录所选资源」。已有记录再次收录会保留标注。

每条记录提供分类、标签和说明。标签每行一个，最多 32 个，每个最多 64 字符；分类最多 128 字符，说明最多 4096 字符。首尾空白会归一，标签按不区分大小写去重。标签、分类和说明保留作者原文，不跟随编辑器语言翻译。

搜索匹配原生资源路径、完整身份、分类、标签和说明。分类筛选区分全部与未分类。列表每页 20 条，选择可以跨页保留；「选择全部筛选结果」会选择全部命中记录。资源移动后可用「刷新整理列表」重新查询路径。

批量整理先移除指定标签，再添加标签。分类和说明只有启用对应覆盖开关才修改；因此可以为一批资源添加共同标签，同时保留各自说明。整批先校验后提交，失败保留原有记录，一次应用对应一项引擎 History。普通编辑、Undo/Redo、保存和关闭重开使用相同原生文档。

「选中资源供设计器使用」将原生资源交给其他 VN 面板。移除整理记录保留资源本身。目录保存的是标注和引擎资产引用，资源发现、导入和身份仍由 Assets 负责。Missing 引用沿用引擎的读取与导入校验规则。

此目录属于 Editor 创作数据。发布游戏时将需要动态使用的资源本身加入附加打包集合；不能把 `.ivnlabels` 目录作为 Player 动态根。分类与标签不改变剧情、图片或音频。

正式编译、搜索/批量原子性、原生引用、History 和保存重开已逻辑验证；当前没有 GUI、鼠标或实际显示验收。
