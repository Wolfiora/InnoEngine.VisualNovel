# 限时选项

在节点图或剧本中选择“选项”，设置正数超时和默认选项。时间为零表示不限时；默认目标必须存在，运行时还必须可见且可选，否则产生带源位置的错误。

三套内置主题的阅读页包含可编辑的剩余秒数与进度条。打开菜单时剧情计时暂停，恢复阅读后继续；存读档恢复同一剧情等待时钟，回滚恢复检查点当时的时间。没有单独运行的 UI 定时器。

界面设计器可以选择以下只读字段：

| 字段 | 用途 |
|---|---|
| `choice.timed` | 当前是否正在限时选择，用于条件显隐 |
| `choice.timeRemaining` | 精确剩余秒数 |
| `choice.timeRemainingRatio` | 1 到 0 的剩余比例，进度条范围配置为 0～1 |
| `choice.remainingSeconds` | 向上取整的剩余秒数，用于文字显示 |

这些值不能由滑块或写入动作修改；要改变规则，编辑选项节点。离开限时选项时，计时控件隐藏。玩家输入、存档、回滚和选择继续走普通 VN 会话与原生状态链。实际画面尚未实机验收。
