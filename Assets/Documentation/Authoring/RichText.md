# 文字格式与节奏

对白属性中展开「文字格式与节奏」。这里显示去除格式标记的正文，起始位置从 0 开始计数；一个组合字符或完整 emoji 算一个字素。选择范围后可以应用粗体、斜体、字号、颜色、字体资源键、描边、阴影、局部速度或注音。应用格式和普通正文编辑使用同一文档事务与引擎 History。变量占位符和已有注音必须整体选择，避免拆开语义。

UI 文本默认按字面显示。勾选「解析文字格式」后可使用相同格式表单；绑定当前对白的控件直接接收完整排版内容及揭示位置，不需要额外打开开关。未揭示的内容仍参与排版，因此文字出现时不会重新换行或移动已经显示的字。

在界面设计器的「页面富文本资源」中为字体和行内图片添加唯一资源键，并绑定 File Browser 中选中的原生字体/图像。文字使用这些键引用资源；这些是真实资产引用，参与原生依赖收集。删除仍被使用的键会产生 Missing 错误，不会悄悄换成其他资源。行内图像以当前字号为高度，保持图片比例。

常用操作无需手写格式；高级编辑也可直接使用以下标记：

| 用途 | 标记 |
|---|---|
| 粗体、斜体 | `[b]正文[/b]`、`[i]正文[/i]` |
| 字号、颜色 | `[size=36]正文[/size]`、`[color=#FFD080]正文[/color]` |
| 字体 | `[font=letter]正文[/font]` |
| 描边、阴影 | `[outline=2]正文[/outline]`、`[shadow=2]正文[/shadow]` |
| 装饰颜色 | `[outlinecolor=#000000]…[/outlinecolor]`、`[shadowcolor=#00000080]…[/shadowcolor]` |
| 注音 | `[ruby=かんじ]漢字[/ruby]` |
| 行内图像 | `[icon=heart]` |
| 停顿 | `[pause=0.4]` |
| 局部速度 | `[speed=0.5]缓慢文字[/speed]` |
| 左方括号字面值 | `[[` |

注音内部是连续正文，不能嵌套图像、样式或节奏标记。样式可以在注音外嵌套。注音与基字作为一个排版单元换行；注音整体出现。字号按页面设计单位解释，并随玩家字体缩放设置放大。文字对齐和行距在控件属性中设置。

对白的「句末标点停顿秒数」可统一对 `。！？.!?…` 增加等待。局部速度和暂停由逻辑时间求值；存档保存已经解析的文字和当前进度。第一次推进会完成文字和剩余停顿，下一次推进才离开该句。变量插入的玩家姓名等数据始终按字面处理，不能注入格式或停顿。

正式编译会定位未知、未闭合或参数越界的格式标记。此文描述已接入的实现；实际字体、美术和多语言排版仍需之后的实机验收。
