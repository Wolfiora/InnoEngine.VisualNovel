# 游戏多语言

游戏语言和编辑器工作语言分开。新建向导生成 `.ivnlocale`，包含简体中文和已知教学文本的英文译文；作者自定义的内容不会被假装自动翻译。

1. 打开「VN 多语言」，新建或打开翻译表，添加语言标识与名称，例如 `ja` / 日本語。
2. 在 File Browser 选择游戏，使用面板的同步操作抽取已保存章节、界面和收藏文字。对白、选项、UI 元素和收藏使用稳定文本 ID。
3. 选择目标语言，编辑译文、语音提示 ID 和复核状态。源文有变量时，译文必须保留相同插值字段。
4. 保存翻译表，将它关联到游戏，再选择默认游戏语言。语音提示必须是该游戏声明的非循环 Voice 资源。
5. 在实际游戏设置页选择语言。当前对白会重排和更新，保持剧情位置与揭示比例，不再次执行解锁、赋值或添加历史。

原文摘要变化时，旧译文保留供复核，运行时回退原文。修改角色名或文案不会通过数组序号匹配翻译。读取旧语言下的同构建存档，继续使用玩家当前语言偏好；语言偏好不属于剧情回滚。

## CSV / TSV 交换

导出写入当前项目的 `artifacts/Exports`，面板保留明确路径。输入待导入文件的完整路径后读取，在「翻译列映射」中将七个语义字段分别对应表头位置。标准表头自动识别；自定义和重复表头需明确选择位置。改变 CSV/TSV 格式或列映射会清除旧预览。CSV 引号、逗号、制表符、多行和 Unicode 会保留。

预览按 40 条分页，可搜索 ID、原文或译文，按语言或提示筛选，查看每条原文、译文、状态、原文摘要及语音 ID。长文本详情会注明截取，实际导入保留全文。每批最多十万条、输入文本最多 16 MiB，超出时拆分文件。

仅有效记录可应用；重复的文本/语言、原文冲突、无效语言或变量占位符错误会阻止对应记录。同一新文本 ID 在不同语言中也必须对应同一原文。旧版本译文可以保留供复核，运行时仍回退原文。应用前再次核对整个表及有效记录，以一次原生 History 操作提交；可 Undo/Redo，保存后重开仍保留审核状态。原表已改变时必须重新预览。表本身始终使用引擎原生序列化，CSV/TSV 只用于翻译交换。

对白、翻译、界面与收藏正文支持按段落编辑；换段实际保存为换行。原生宿主目前没有导出多行输入控件，因此当前采用逐段表单；光标位置的自由拆行、整篇文本选区等完整编辑体验仍待完善。

「字体与图片」可配置每语言默认字体、有序回退链和图片替换；「缺字检查」使用所选游戏、当前翻译草稿和实际字体声明逐步检查静态文字，支持取消及来源定位。动态变量、玩家输入和扩展生成文字的覆盖不能由静态检查证明。编辑器固定使用英文，没有插件自建的编辑器语言资源或 Settings 项；游戏语言仍由游戏翻译表独立控制。本批次没有中文/英文/日文实机排版或实际字体后端验收。
