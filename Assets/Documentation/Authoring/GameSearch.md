# 搜索一个游戏的全部章节

在 Authoring 菜单打开「VN 全游戏搜索」，或在 Visual Novel 工作区「搜索与书签」页勾选「搜索所选游戏全部章节」。选择 `.ivnproject`，输入正文、角色名、文本/节点 ID、资源键、表达式、标签或备注，点击「使用所选游戏开始搜索」。

搜索只处理所选游戏明确引用的章节，不遍历或另建资产数据库。已打开章节使用当前未保存的原生草稿，其余章节读取 `.ivnstory` 原生源；不会批量打开、保存或切换文档。Missing 节点的作者标注也能参与搜索。

工作按节点分批推进，显示已处理章节和节点数量，提供取消并保留部分结果。每次最多读取一个新章节源；原生源解码仍在编辑器 owner 线程。每个源文件限 64 MiB，每游戏限 2048 章节，结果限 100000 项；这些边界不代表一万节点的性能指标已验收。

结果每页 40 条，显示章节、未保存状态和摘要。点击时先重新检查当前源；节点已删除则提示刷新，节点仍存在但内容变化则按稳定身份定位并提示摘要过期。定位复用引擎文档和主节点选择，不建立另一份故事顺序。

一个章节读取失败不会丢弃其他结果。安装包只读章节会提示先创建项目副本；不会偷偷修改 `Library/Plugins`。开始新的查询、关闭面板或脚本重载会释放旧工作。

正式脚本编译、分批/取消/非匹配节点预算、跨章节相同节点 ID、Missing 标注，以及真实原生文档的 dirty 草稿、未打开源、选择保持和快照隔离已有定向验证。最新完整行为基线仍为此前的 143 项；本批没有 GUI 或实机验收。
