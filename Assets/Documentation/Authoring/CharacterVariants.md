# 制作和维护角色差分

在 File Browser 选择一张已导入的图像，在“VN 角色设计”创建角色。角色保存在原生 `.ivncharacter` 中，姿势、表情和部位编辑都使用同一文档与引擎 Undo/Redo。

## 姿势与部位

姿势由多个语义部位组成，例如身体、后发、眼睛和嘴。给角色添加部位时，它会同时出现在所有姿势中，保留共享部位 ID，使表情能够跨姿势覆盖同一个部位。

复制姿势会保留这些语义 ID，但创建独立的变换、源区域、裁剪、遮罩、动画和颜色数据。可以修改姿势名称，并选择默认姿势。名称用于显示，稳定 ID 用于剧情引用；修改显示名称不会重建 ID。

选中一个部位后，可以为此姿势中的部位设置可读名称，并用 File Browser 中的图像替换“此姿势的部位基础图像”。默认保留作者已经调好的尺寸，也保留遮罩和序列帧；勾选同步像素尺寸才改为新图的宽高。其他姿势和表达式不会被替换。动画帧可能会覆盖基础图像，需在部位动画中单独调整。

源图、裁剪、镜像、像素枢轴、混合与遮罩见 [舞台图像处理](StageSurfaces.md)。

## 表情

新增表情默认继承当前姿势，不强行复制所有图像。对每个部位可设置替换图像、显隐和偏移；“清除此部位表情覆盖”让它重新继承姿势原值。复制表情会复制完整覆盖并建立新 ID，修改副本不影响原表情。

默认表情决定剧情没有指定表情时使用的组合。角色设计器中预览的表情与默认表情是不同的选项，预览不会自动修改游戏默认值。

## 在剧情中使用

在舞台指令选择“显示角色”，再在 File Browser 选中角色并使用所选资源。属性表按名称提供姿势和表情列表；选择默认项会保存为空引用，之后跟随角色默认设置。明确指定的姿势或表情继续使用其稳定 ID。没有关联角色元数据时，保留直接编辑 ID 的高级入口。

## 删除与修复引用

删除姿势或表情时保留至少一个可用项。删除当前默认项前，必须明确选择替代默认项，操作不会猜测该用哪一个。删除失败不改变候选文档，也不产生半完成的默认设置。

明确引用已删除 ID 的剧情保持原引用，发布检查会报告章节、节点、角色和缺失的姿势/表情。修复这些指令后再发布。运行时也会拒绝明确指定但不存在的表情，不会默默改成无表情。空引用继续按角色当前默认值解析。

创作操作限制新增至 256 个姿势、1024 个表情。文件名批量匹配、冻结候选预览和整批提交见 [批量差分导入](CharacterImageImport.md)。完整资源缩略图与本批 GUI 体验尚未验收。
