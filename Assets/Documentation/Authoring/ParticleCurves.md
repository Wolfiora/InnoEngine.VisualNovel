# 粒子生命周期曲线

在「VN 粒子设计」中打开粒子预设，下方「生命周期曲线」分别编辑尺寸和颜色。预览仍使用真实舞台求值器，不需要编写脚本。

关键帧位置采用每个粒子的生命比例：0 是出生，1 是生命结束。尺寸值是设计画布中的高度，宽度继续由宽高比决定；颜色包含透明度。将关键帧放在 0、0.3、1，可以做出先放大再缩小、先淡入再淡出的效果。

选中现有点可修改位置、尺寸或颜色、插值和 Bezier 控制柄。插值作用于当前点到下一点；保持模式直到下一点才切换。新增点的位置不能与已有点重合，每个通道最多 64 点。删除所有点后，该通道恢复使用预设上方的初始/最终值；只有一个点时始终使用它的值。首尾点之外保持最邻近点，不进行外推。

修改通过原生文档 History，支持撤销、重做、保存与重开。播放时冻结曲线；存档和回滚恢复粒子种子及逻辑时间，求值不受此前拖动或帧间隔影响。新建不同设计分辨率的模板会等比缩放尺寸曲线，生命比例保持不变。

内置「萤火」提供带尺寸峰值、渐入和渐出的起点。本批只验证逻辑与原生数据；尚未进行 GPU 视觉验收。
