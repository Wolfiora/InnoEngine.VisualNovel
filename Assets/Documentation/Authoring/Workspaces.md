# 按任务切换工作区

Visual Novel 主面板提供写作、流程、演出和界面四个任务入口，以及保留全部工具的集中视图。所有入口使用现有原生文档和 History，不生成另一份剧本或页面。

| 入口 | 使用方式 |
|---|---|
| 写作 | 故事入口与片段导航、剧本卡片/紧凑/阅读稿、当前指令属性、实际游戏预览 |
| 流程 | 同一故事导航、大节点画布、当前指令属性、同一预览会话 |
| 演出 | 打开原生舞台与演出时间线面板，可继续进入角色设计 |
| 界面 | 打开原生页面与主题设计器，编辑布局、绑定、动作和动画 |
| 全部工具 | 章节结构、变量、搜索与书签、剧本交换、完整预览配置、调试与编译诊断 |

写作和流程在宽面板中提供可调整列宽的三栏；较窄时切换为内容、导航、属性和预览标签。每个滚动区域只负责自己的内容，不要求横向挤压属性表单。演出、界面与其他任务面板的停靠位置由引擎管理；插件不改写引擎的全局布局配置。

右侧预览与完整预览页共用一个会话。先明确选择 `.ivnproject`，可以从真实游戏入口运行；局部初始变量、舞台快照、路线用例和断点放在「预览设置与调试」。定位当前指令会共享故事选择。切换任务或隐藏预览时暂停其显示与音频，返回时保留会话；停止或关闭 owner 时释放会话。

「角色、声音、多语言、收藏与发布」中的任务选择器打开对应的正式原生面板。页面、角色、音频和剧情使用同一套资源文档，可以通过全局资源选择关联。

工作区布局和交互尚未实机验收；功能逻辑证据与正式编译状态以仓库实施状态为准。
