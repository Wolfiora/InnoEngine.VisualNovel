# 角色姓名、头像与对白关联

在「VN 角色设计」中编辑显示名、别名、对白姓名颜色和独立头像。头像与舞台姿势相互独立；切换立绘不会替换头像。内置角色使用原创简洁矢量教学素材。

在对白检查器中选择角色资源并点击「关联角色」，或填写游戏角色库中的稳定资源 ID。把角色资源关联到游戏后，留空「姓名覆盖」即可使用角色姓名；旁白同时留空角色 ID 和姓名。姓名覆盖支持现有变量插值，优先于角色默认名。

默认姓名按角色稳定 ID 提取一次翻译，不为每句复制一条姓名翻译。覆盖姓名仍按台词 ID 翻译。姓名是普通文字，方括号不会被当成富文本标签。运行会话冻结角色资料，编辑资源后需要重新建立预览会话。

默认 ADV 页面已使用可编辑的图片控件绑定 `dialogue.portrait`，可见条件是 `dialogue.hasPortrait`，使用 Contain 保持比例。没有头像时不占横向空间。姓名绑定 `dialogue.speaker`，使用角色颜色；`dialogue.characterId` 可用于自定义 UI。

配音管理的审核列表与导出稿会解析关联角色姓名。导入前如果角色改名，会要求重新匹配，避免录音稿与当前内容不一致。角色 ID 缺失会给出错误，不会静默变成旁白。

游戏设置页为角色库中的每个角色生成独立音量与启用开关。角色音量叠加语音分类和总音量，不改变资源原始音量。设置属于玩家偏好；读档或回滚不会恢复旧的静音设置，历史语音重播仍使用原角色的设置。默认姓名覆盖不改变这个身份。没有关联角色的语音继续使用语音分类设置。

存档保存剧情位置和已解析对白；头像、颜色从当前构建的角色资源恢复。普通存档仍严格匹配内容构建，不提供跨构建迁移。

本功能尚未进行实机画面、输入设备或易用性验收。
