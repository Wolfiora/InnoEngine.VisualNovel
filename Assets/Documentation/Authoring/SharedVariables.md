# 多章节共享变量

章节变量、共享变量和页面字段都可填写「分组」及「用途说明」。分组只整理创作列表，不改变稳定 ID、作用域或对白插值；最多 128 字符，说明最多 4096 字符。章节/共享列表按组显示，可同时搜索身份、名称、分组和说明，每页 40 项。选中的声明会继续保留在检查器中。

说明随原生源、编译声明、复制粘贴及组件字段提取保留；引用映射到已有变量时，以目标声明为准。仅修改整理信息不改变变量交接所需的类型、作用域和默认值契约。所有编辑沿用原生文档 History，不使用额外变量索引或说明文件。

`.ivnvariables` 是引擎原生资产，保存一组 Game 或 Global 变量定义。章节明确引用一个变量库，并保留自己的章内声明。Local 调用局部变量仍属于章节；同一稳定 ID 不允许同时存在于库和章节中。编译器合并并复制有效声明，运行游戏只使用编译产物，不在执行途中读取或修改创作库。

新建游戏向导会创建 `Variables.ivnvariables`，将模板的 Game/Global 定义交给它，并让章节引用同一份资产。在「VN 共享变量」面板可创建库、设置稳定 ID、类型、作用域、默认值和枚举成员。编辑后保存，章节参数选择器即可读取更新后的已导入定义；运行中的旧会话保留启动时冻结的程序。

已有章节在「变量」页引用 File Browser 中选择的库。若存在同名章内定义，必须明确选择「允许移交完全相同的章内声明」，并且作用域、默认值和枚举成员全部相同。不会猜测覆盖哪一方。更换库前，先「解除引用并保留全部声明」，再关联另一份库；解除、关联和普通字段修改均走同一原生文档与 Undo/Redo。

章节页列出库定义及当前图中的使用节点，定义本身在库面板编辑。库面板可按明确选择的游戏查询节点引用，包括已经打开的章节草稿；查询不建立另一套资源索引。其他游戏、UI 绑定和收藏条件不在这个节点查询的证明范围内。删除或改类型前先处理使用位置；编译诊断仍会指出失效的章节和节点，不能自动改写故事意图。

未分配和缺失库分别显示。缺失时保留原生 GUID 与已知路径；路径只作提示，不作为身份替换别名。若明确清除缺失引用，图、节点参数与章内声明仍保留，原始关联可从 History 撤销恢复；无法凭空恢复丢失的默认值。

图复制会携带实际使用的有效声明。粘贴到已有同一声明的目标库时，不再生成重复章内定义；类型、作用域、默认值或枚举成员冲突会在修改图前拒绝。跨章节共享不改变节点 ID、控制流或局部调用栈规则。

预览捕获未保存变量库，重新编译所有受影响的所选游戏章节；活动草稿继续使用同一份捕获值。后续编辑不会修改已有预览快照，也不会保存源或改写 canonical 程序。当前预览准备同步执行，大项目取消和增量准备仍是后续工作。

已通过正式 Scripting API 编译和三项相关定向契约，包含原生 History/依赖/保存重开、完整向导与展示路线、未保存库的依赖章节重编译和候选失败隔离。保存库后的章节更新通过额外原生依赖契约验证；导入器显式使用引擎源与 Artifact 失效依赖。完整行为基线见实施状态。实际编辑器操作、规模、GUI 和 Windows 成品没有本批实机验收。全局变量生产落盘仍受 Runtime 原生根 codec 接入缺口影响。
