# 镜头跟随

「舞台与角色」指令的 FollowCamera 操作跟随已经存在的角色实例或舞台图层。角色显示后，可以从当前章节的角色实例列表选择；在资源浏览器选择舞台，还可以列出该舞台的图层。跨章节目标可手动指定 `character/实例名称` 或 `stage/图层 ID`。

屏幕锚点 X / Y 使用 0～1：0 为左或上，0.5 为中心，1 为右或下。X / Y 为额外世界坐标偏移，镜头缩放和旋转继续可编辑。跟随基于作者枢轴和时间线位移；角色的差分、眨眼或嘴型不会因为部位尺寸改变镜头目标。

镜头同时应用自己的时间线通道，按当前缩放和旋转把目标投射到屏幕锚点。求值使用当前逻辑状态，不积累上一帧误差。暂停、跳时、快照、存读档和回滚保留相同的跟随目标与构图。

StopCameraFollow 冻结当前逻辑构图，保留仍在播放的镜头轨道。普通 SetCamera 显式切回自由镜头。隐藏跟随角色或更换舞台移除了目标时，也会先冻结构图，再移除目标。目标在首次执行时尚不存在会产生带请求节点位置的错误。

并行分支中的跟随由该任务拥有；等待任一完成而取消它时会停止跟随。编译器拒绝不同并行分支同时写镜头。不会因为并行任务取消而停止其他目标后来拥有的跟随。

本功能不提供图像识别或基于设备的追踪；它直接使用 VN 舞台中已有对象的声明性位置。当前仅做正式编译和逻辑验证，实际 GPU / 编辑器操作另行验收。
