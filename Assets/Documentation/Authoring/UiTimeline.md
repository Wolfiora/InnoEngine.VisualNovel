# 在演出时间线中控制 UI

UI 轨道沿用现有演出片段、关键帧、缓动、标记和剧情演出节点。它与角色、镜头和音量共用一个逻辑时钟，不启动另一套播放器。

1. 在时间线中添加目标槽，例如 `dialogue-panel`。
2. 为这个槽添加 X、Y、ScaleX 或 Opacity 轨道并编辑关键帧。
3. 在剧情演出节点选择片段，从所选游戏的 UI 目标中选择页面和元素。
4. 在时间线中指定一个页面作为明确预览状态，把同一槽绑定到它的元素，再拖动时间查看。

| 通道 | 解释与范围 |
|---|---|
| X / Y | 相对于布局的设计像素偏移，范围 −10000～10000 |
| ScaleX | UI 的统一缩放倍率，范围 0.1～4；不改变文字换行 |
| Opacity | 相对透明度，范围 0～1 |

系统目标的稳定表示为 `ui/页面角色/元素ID`；选择器会列出它们。重复列表中的模板元素会把同一个轨道样本应用到每个实例，行身份、变量和输入仍各自独立。轨道不会更改节点顺序、页面状态或控件的作者参数。

只有在该页面角色的所有主题变体中都存在的元素才可作为稳定目标。若某个主题删除或改名了目标，游戏准备或发布检查会拒绝对应演出并给出剧情节点与目标位置；不会静默丢掉轨道。

暂停、继续、取消、跳时、等待标记、存读档和回滚使用原来的演出状态。取消后移除轨道样本，恢复布局与样式。玩家的减少动态效果设置沿用演出片段的「剧情必要」策略；包含音量的混合片段仍保留音频的逻辑时间。

UI 事件动画属于独立的临时表现通道，可在时间线结果上叠加；命中区域、裁切和整组透明度会统一计算。时间线拖动不会执行页面按钮或重复剧情副作用。

时间线可以只指定 UI 页面进行纯预览；也可以同时指定舞台，查看二者的组合。预览使用示例绑定数据，实际剧情内容在路线预览或完整游玩中检查。音量轨道在拖动时只显示数值，不反复播放声音。
