# 时间线标记、吸附与范围复制

在「VN 演出时间线」中，点击「在当前时间添加标记」，可以创建具有稳定 ID、名称和时间的同步点。列表选择标记后可改名、修改时间或删除；上方网格中的橙色标记可以拖动。剧情引用稳定 ID，改名不会改变身份。每个片段最多 1024 个标记，时间必须在片段内。

剧情「演出」指令选择 WaitMarker（等待标记），填写实例 ID，再选择或填写标记 ID。它等待该实例**首次**达到标记的逻辑时间；循环不会变成等待下一轮。实例不存在或已取消时结束等待，活动实例缺少指定标记时报告具体剧情位置。被减少动态效果抑制的可选片段立即释放等待，重要演出保留正常时间。

等待位置、实例播放时间与编译指令共同参与普通会话快照；不保存回调或协程栈。拖动和 Seek 只改变声明性的时间，不触发脚本、解锁、存档或外部动作。重新向后 Seek 后，尚未结束的等待按当前逻辑时间判断。

勾选吸附后，拖动与写入使用明确的秒数间隔；数值预览时间仍可精确输入。范围复制指定源开始/结束，将区间内的关键帧复制到当前预览时间，可以操作当前轨道或全部轨道。默认拒绝与现有时间冲突的复制；勾选明确覆盖后，只替换碰撞时间，保留其他关键帧、标记、曲线和原始范围。浮点时间以相对 1e-9 容差判定碰撞。

拖动、标记修改和整批复制复用引擎 History；Esc 或失焦取消当前拖动。内置 20 个动作提供 start、middle、end 标记，演出教学包含真实中点等待。

正式 Scripting 编译和两项标记/范围逻辑契约通过，纳入 137 项完整行为基线；内置动作与五组原生教学源已刷新。未进行 GUI 或实机验收。
