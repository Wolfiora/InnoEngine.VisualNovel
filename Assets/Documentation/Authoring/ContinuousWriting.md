# 连续写作与执行段

剧本视图将连续单一路径显示为执行段；顺序来自真实连线。在线性边上插入指令后，新指令出现在它实际执行的位置。分支、汇合、公开入口和跨片段目标保持明确边界，循环不会无限展开。未连接节点、Missing 节点及未归属节点仍可查看，不会因视图组织而丢失。

选中一条拥有唯一有效后续连接的对白，点击「继续写下一句」。新对白保留角色、动态姓名、阅读布局、位置与文字速度，获得新的节点和文本身份。录音关联清空；NVL 不会为每条新对白重新清页。随后在属性表单填写正文。原来的后续指令接到新对白之后，整个操作可通过引擎 History 撤销或重做。

卡片、紧凑与阅读稿共用有限执行段投影和可见行布局，只绘制视口及附近内容。节点图、诊断、跳转目标或「定位所选节点」会将相同身份滚动到可见处。Undo/Redo、源还原及文档修订使投影失效；投影不保存另一份语义。

编辑模式中可从卡片标题拖动到另一标题的上半部或下半部，分别表示插入其之前或之后。这里使用真实的唯一输入或输出连线；分支输出和汇合输入不能靠卡片位置猜测，请拖到卡片下方明确列出的执行连线。公开入口、并行边界和多输出指令不能当作普通单卡片移动。

同一线性段中的拖动、上移/下移按钮及 Alt+上/下直接提交一项引擎 History。文字输入时不处理换序快捷键。跨分支、汇合或片段时先列出三条执行边的变化，明确确认后才应用。过期拖动载荷或旧预览不能修改新修订。节点身份、文本身份、资源、图中位置和现有边身份保持不变。

Ctrl/Super+Enter 继续同角色对白；普通 Enter 在当前行后换段。任意光标拆分、多段选区及原生多行文本体验尚未完成。单次原生复制和章节编译仍不可抢占，不宣称大型章节 100ms 指标通过。以上鼠标、键盘与输入法操作没有实机验收。
