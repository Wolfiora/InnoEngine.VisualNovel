# 使用内置资源

打开「Authoring → VN 内置资源」。分类包括三套主题、背景、角色、动作、粒子、转场、屏幕效果、音频提示与图标；名称、用途和路径都可以搜索。目录仅描述本插件已打包的预设，身份、导入、依赖和加载仍由引擎 Assets 负责。

选中舞台类预设后，可以播放、暂停或直接输入逻辑时间。动作使用明确的角色/camera 目标槽；粒子使用固定随机种子；转场显示真实的前后舞台。反复拖动时间不会执行剧情、解锁、存档或用户脚本。可以勾选「检查减少动态效果」验证静态策略。

主题预览可选择全部 18 个页面，使用正式 UI、文字与渲染适配链。图标是白色透明 PNG，在界面设计器的「图片着色」中修改颜色。点击「选择此资源供其他面板使用」后，可在相应设计器使用当前原生选择。

## 复制和修改

安装资源保持只读。点击「创建可编辑项目副本」，会在 `Assets/Game/Resources/` 下创建新的原生资产身份与资源键，再打开共享文档。随后在角色、舞台、时间线、粒子、效果、主题或音频设计器修改；所有参数修改沿用引擎 History。

复制主题还会复制它引用的页面，并重建主题的页面映射。字体和图像保留原生不可变资源引用，不把安装目录的解包路径写入故事。图标像素的修改使用矢量源或自己的绘图工具；页面直接引用图标即可，不要求复制 DLL 或手工配置渲染器。

生成新游戏时，向导会创建三套主题和 54 个页面，以及六个舞台、两个角色的项目定义副本。教学章节先显示角色，再按选项切换海边或林间背景。上述内容位于普通 `Assets/Game/`，不会让发布游戏依赖 `~Samples`。

## 音频试听

资源浏览器和音频提示面板都提供显式「试听」按钮、暂停、停止和定位。打开资源不会自动发声。试听与正在游玩的游戏分别拥有声音；更换试听资源、关闭面板或脚本代际结束时释放声音。准备新声音失败时，原来的试听仍可停止或重试。

本次开发验证只通过替身音频输出检查了这些逻辑，没有播放声音，也未做设备或听感验收。

## 数量与许可

当前包含 68 个图标、6 张 1920×1080 背景、2 个分层角色（各 2 姿势、6 表情）、20 动作、8 粒子、12 转场、10 屏幕效果、20 UI 音效及 3 段教学氛围。原创资源采用随附 Apache License 2.0，字体使用独立 OFL 许可。

这些是简洁的教学资源；数量与原生导入通过不等于成品美术、所有缩略图、GUI 易用性或整套资源库已经验收。具体实施证据见项目的 `Documentation/Specifications/BuiltInResourceManifest.md`。
