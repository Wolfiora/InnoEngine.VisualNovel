# 剧情诊断与语言

在工作区「全部工具」点击「检查章节」。编译失败不会生成可运行的半成品；警告仍允许编译，例如未从任何公开入口到达的节点。诊断包含引擎等级、稳定错误代码和说明。

点击节点诊断定位同一图/剧本节点。原生连线诊断保留具体边身份，并定位这条边仍存在的端点；章节级问题没有虚构目标。修改节点身份、删除连接或切换章节后应重新检查。

编辑器语言在引擎 Settings 的 Visual Novel/Language 设置，与游戏语言独立。VN 自有编译规则在显示时翻译已审核模板，再填入资源名、变量名、节点 ID 等原值。花括号或 `##` 出现在用户名称中不会变成格式标记或控件身份。原生图规则和未声明的扩展错误保留原文，不能据此承诺所有第三方消息都自动翻译。

作者操作错误保留普通异常类别、参数名和原始原因。分步预览与资源复制失败保留已完成输出或先前有效会话。错误显示语言不会修改剧情图、可执行程序、存档内容或构建指纹。

这些路径已通过正式脚本编译及行为/原生数据验证；当前未进行 GUI、输入法或英文上手实机验收。
