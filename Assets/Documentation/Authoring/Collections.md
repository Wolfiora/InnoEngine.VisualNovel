# 收藏、鉴赏与回想

新建游戏向导生成可编辑的 `Collections.ivncollection`，并提供音乐、回想、词条的教学条目。所有鉴赏页面也都是普通 `.ivnui`，可在界面设计器修改。

## 创作

1. 从 Authoring 打开「VN 收藏」，新建或打开收藏库。
2. 输入稳定标识，例如 `cg.chapter1`，选择 CG、音乐、回想、结局、词条或角色资料，然后添加条目。
3. 填写名称、正文、作者。多段正文按行编辑；“在当前行后换段”会写入真实换行，删除空行不会删除非空正文。
4. 在 File Browser 选择图片，点击“使用所选图片”。CG 需要图片，播放器可使用封面。默认按完整图片等比显示。
5. 选择游戏资产后，点击“使用所选游戏的变量与资源”，从列表选择音乐提示、回想章节及公开入口，使用递归表达式表单配置条件。
6. 保存收藏库，在「VN 游戏」选择该游戏，将收藏库作为资源关联并保存。

条目标识用于剧情和全局进度，不随名称、列表顺序或画面位置改变。删除前会确认；删除已引用条目后，游戏校验会报告失效的解锁指令，不能静默改指向。

## 解锁

“初始解锁”适用于默认可用内容。故事中可添加“解锁鉴赏内容”指令，填写收藏条目 ID。也可配置纯 Boolean 自动条件；随机操作和调用局部变量不用于自动规则，避免查询改变随机结果或依赖不明确的调用上下文。

解锁、已读与声明的全局变量在 `GlobalProgressState` 中单独保存。普通存档和回滚不撤销解锁。当前主机的 Runtime 原生序列化入口缺口仍影响正式全局进度自动落盘，见仓库实施状态；不能把会话内正确保留误认为退出游戏后已经完成生产持久化。

## 玩家页面

标题的“鉴赏与资料”进入分类入口。列表支持搜索已解锁名称、分页、键盘焦点及锁定占位；锁定条目不显示标题、正文或图片。CG、结局、词条和角色进入详情；音乐进入播放器；回想启动独立会话。

音乐支持暂停/继续、前后切歌、单曲循环和随机顺序。即使原 BGM 提示为循环资源，鉴赏播放也按单次实例完成，再执行播放器策略。离开音乐页恢复进入试听前的曲目、位置、淡变、暂停及循环状态。

## 回想初始状态

回想需要明确的章节及公开入口。可添加非全局变量初值，在第一条指令执行前应用。默认舞台与变量来自游戏定义；不要把主路线当前舞台当作回想前置条件。

回想拥有独立剧情、舞台、音频、变量、阅读和解锁范围，使用主游戏进度的副本。它不运行主游戏时间，也不写回变量和解锁。普通保存/读取关闭；“退出回想”或运行到结束后返回原页面并恢复原声音。回想不能嵌套。可回滚的边界仍属于回想自身。

本功能的正式脚本和行为逻辑由契约测试验证；本批次不进行实机、图形或听感验收。
