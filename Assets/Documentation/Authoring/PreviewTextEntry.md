# 预览中的文字输入

预览画布使用与 Player 相同的阅读、菜单和按住快进映射；点击画布取得键盘操作范围，切换窗口、面板或输入原生表单时释放捕获。暂停、隐藏或停止预览也会退休本次输入。

画布中的文本框取得焦点，或打开选择器搜索后，下方出现“预览中的文字输入”。可在这里用编辑器原生文本控件输入中文、组合字符或 emoji，内容同步到当前文本框或临时筛选查询。清空也是一次正常编辑；长度规则仍由原有 UI 和剧情数据校验。玩家姓名等输入有效时，可用“提交预览输入”确认。普通切换面板会关闭弹层，只有明确正在编辑的原生输入控件保留它的查询。

这些操作通过普通 UI 输入与真实会话完成；路线记录保留实际提交结果，不写回剧情源或测试初始值。当前正式 EditorUiInput 没有公开提交文字缓冲区，因此不把按键猜成字符，也不宣称画布里已经直接接入完整输入法。上述原生表单提供当前可用的编辑器输入路径；最终 Player 的提交文字继续来自正式视口输入。

未做 GUI、真实输入法或设备验收。
